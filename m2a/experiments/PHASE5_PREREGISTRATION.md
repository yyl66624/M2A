```
窗口存在  ⇔  β · Δ ≥ κ_F(α),        Δ = drive(点火构型) − drive(静默构型)
```

## 1 V1：L3 残差归因

### 1.1 被解释的对象（不得改口径）

读out 与 Phase III/IV **完全相同**：`Δ(q) = |Q(A|(mx=9, step=1, cue=1)) − Q(A|(mx=9, step=1, cue=0))|`，
律为 `Δ_law(q) = γ(v_B − c)(2q − 1) = 0.36(2q − 1)`，`q ∈ {0.5, 0.6, 0.7, 0.8, 0.9, 1.0}`。
Phase IV 的 Q-learning 读数（`phase4_results.json`，10 种子均值）是本轮的**锚定对象**。

### 1.2 设计：五臂单因子 + 精确不动点

`BASE` = `p3_mechanisms.train_cue_agent`（**逐字复用，不改该文件**），RNG 调用序列一致。

| 臂 | 唯一变动的因子 | steps | 目的 |
| --- | --- | --- | --- |
| `base` | ——（锚定臂） | 100 000 | 复现 Phase IV 读数（G0 式锚定） |
| `long` | 只有样本量 ×4 | 400 000 | 区分**瞬变**与**不动点** |
| `noexplore` | 第二步 ε = 0（去掉探索；第一步覆盖不变） | 100 000 | 检验"探索噪声" |
| `greedy_first` | 第一步改为贪心（撤销 P3-A2 的均匀覆盖） | 100 000 | 检验**行为策略的访问加权** |
| `sarsa` | 自举项由 `max` 改为行为策略下的期望 | 100 000 | 检验"第二动作策略" |
| `dp(<臂>)` | 同一算子的**精确访问加权条件期望不动点**（无采样，值迭代到 <1e-12） | —— | 判据：DP 是否等于该臂的 MC 极限 |

DP 的定义：枚举全部环境抽取 `(v, mask, cue)`（`P(v_H)=0.8`，mask ∈ {[1,0],[0,1],[1,1]} 各 1/3，
cue 以概率 q 等于 `mask[1]`），按各臂的行为策略计算 `E[target | (s,a)]` 的**访问加权**比值，
迭代至不动点；未被行为策略访问的 `(s,a)` 保持 0.0（与采样管线一致）。
DP 使用**渐近**行为策略：ε 取退火终点 0.02，γ=0.9，α 采用 `1/(1+n)` 的极限（等权访问均值）。

### 1.3 判据（先固定，按序读）

| 编号 | 判据 | 容差 |
| --- | --- | --- |
| **V1-A0（锚定）** | `base` 臂 10 种子均值 ↔ `phase4_results.json` 的 `q_learning.mean` 逐 q 一致 | **≤ 0.005**；任一 q 超界 ⇒ V1 整节 NOT VALID |
| **V1-A1（DP 充分性）** | 每一臂、每一 q：`|Δ_mc − Δ_dp(该臂)|` | **≤ 0.008** |
| **V1-A2（偏差定位）** | `|Δ_dp(base) − Δ_law|` 的中段最大值，与 `|Δ_mc(base) − Δ_law|` 的中段最大值之比 | **≥ 0.75** ⇒ 偏差主要住在不动点 |

**归因规则（互斥，按序取第一条成立的）**：

1. **J_FIXED_POINT**：V1-A1 全过 **且** V1-A2 比值 ≥ 0.75 **且** `long` 臂的中段偏差**未**降到 `base` 的一半以下
   ⇒ 结论：残差是**指定估计器算子的不动点性质**（行为访问加权下的条件期望），不是探索噪声、不是有限样本、不是律本身。
2. **J_TRANSIENT**：`|Δ_dp(base) − Δ_law| ≤ 0.005`（DP 复现律）**且** `long` 把中段偏差降到 `base` 的一半以下
   ⇒ 结论：残差是**有限样本瞬变**。
3. **J_EXPLORATION**：`noexplore` 把中段偏差消去 ≥ 80%，而其余臂基本不动 ⇒ 结论：残差由**探索**携带。
4. **J_NOT_DECISIVE**：以上皆不成立 ⇒ 登记为**未解释**，不得写机制解释。

**附带登记（不作判据）**：每臂每 q 的 10 种子 sd 与 `sd/√10`；若某格的 MC↔DP 间隙小于其自身标准误，
只说"与该格的测量精度一致"，不说"已验证"。

## 2 V2：L1 的多通道与软合取

### 2.1 模型

`p = F(β(T_n(x) − θ))`，`x_i ∈ [0,1]`，三条 t-norm：

| t-norm | `T_n(x)` |
| --- | --- |
| 乘积 | `∏ x_i` |
| Łukasiewicz | `max(0, Σx_i − (n−1))` |
| Gödel（min） | `min_i x_i` |

三类构型（`drive` 的两端）：

| 构型 | 静默端 | 点火端 | 预测 `Δ` |
| --- | --- | --- | --- |
| **硬 AND**（`s=0`） | 至多一路为 1，其余 0 ⇒ `T=0` | 全 1 ⇒ `T=1` | **1**（与 n 无关） |
| **单路弱化** | `n−1` 路为 1、一路为 `s` | 全 1 | `1 − s`（三条 t-norm 相同） |
| **等度弱化** | 全部 `n` 路为 `s` | 全 1 | 乘积 `1 − sⁿ`；Łuk `1 − max(0, ns−n+1)`；min `1 − s` |

### 2.2 网格

`n ∈ {2,3,4}` × 3 条 t-norm × `s ∈ {0, 0.25, 0.5, 0.75}` × 三基底（logistic/probit/Gumbel）× `α=0.05`。
`β*` 由 θ 网格上的存在性判定 + 对 β 二分（容差 1e-3）求得。

### 2.3 判据

| 编号 | 判据 | 容差 |
| --- | --- | --- |
| **V2-B1** | 数值 `β*` ↔ 解析 `κ_F(α)/Δ_pred` | **≤ 0.05**（沿用 Phase IV），且相对误差 ≤ 2% |
| **V2-B2** | 硬 AND 的 `β*` **不随 n 改变**（n=2,3,4 三值两两差） | ≤ 0.02 |
| **V2-B3** | 等度弱化下三条 t-norm 的 `β*` **分离方向**与预测一致：**Gödel(min) ≥ 乘积 ≥ Łukasiewicz** | 全部一致 |
| **V2-B4** | 在 `β*+1` 的窗口内做 MC（每格 20 000 次）：静默端 ≤ α、点火端 ≥ 1−α | ≤ 0.005 |

任一不过 ⇒ L1 的多通道推广记 **REFUTED**，不得改口径重测（见 §4 停止条件）。

## 3 V3：L2 的串联门（极性乘积）

### 3.1 模型

m 级串联：`p = F(β(x·∏_{i=1..m}(2o_i − 1) − θ))`。预测三条：

1. **符号 = 极性乘积**：`sign(∂p/∂x) = sign(∏(2o_i − 1))`；
2. **死门**：任一 `o_i = 0.5` ⇒ 乘积为 0 ⇒ 对一切 x 恒定（`max|Δp| < 1e-12`），且**任何有限 β 都无窗口**；
3. **增益连乘衰减**：串联链作为合取的门控时，`Δ = (1 − T_silent)·|∏(2o_i − 1)|`，
   故预测 `β*_chain = κ_F(α)/Δ`（与 V2 同一门槛律）。

### 3.2 网格与判据

`m ∈ {1,2,3}` × 每级 `o ∈ {0, 0.25, 0.5, 0.75, 1}`（`o=0.5` 只在 m≥2 的一个位置插入）× 三基底；
链-合取组合：硬 AND（n=2）与等度弱化 `s=0.5`、`o=0.75` 全链 × 三基底。

| 编号 | 判据 | 容差 |
| --- | --- | --- |
| **V3-C1** | 全部 (m, o 组合, 基底) 的符号与 `sign(∏(2o_i−1))` 一致 | 全部通过 |
| **V3-C2** | 含 `o=0.5` 的链：曲线恒定 **且** `β ≤ 200` 内无窗口 | max\|Δp\| < 1e-12 |
| **V3-C3** | 还原性负对照：m=1、`o=1`、硬 AND、logistic ⇒ 与 Phase IV 的 **5.889** 一致 | ≤ 0.005 |
| **V3-C4** | 链-合取门槛：数值 `β*_chain` ↔ `κ_F/((1−T_silent)·∏|2o_i−1|)` | ≤ 0.05 且相对 ≤ 2% |
