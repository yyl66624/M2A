## 2 这关闭了什么：`P13-O1`，以及 Phase XIII 那次 FAIL 的定量解释

Phase XIII 的 **B1** 要求 `J ≥ 40` 时 `β*_J` 进入闭包值的 **0.2%** 以内，实测 **0.49%** 而判负（X-38）。
本轮把同一件事写成**速率式**而不是**收敛门限**：

```
δ(J) = 1/(J+2)      在 lo_J = 0.5 − 0.5/(J+1)、L = 0.5 下为恒等式（κ 消掉 ⇒ 与基底、与 k 无关）
```

于是旧读数不是"没收敛"，而是**按律收敛**：`J = 200` 处律预测 **0.4950%**，本轮同仪器实测
**0.4896% / 0.5113% / 0.4906%**（logistic / probit / gumbel）。由律直接算出旧容差需要的网格：

| 想达到的 `δ` | 需要的 `J`（由 `1/(J+2)` 反解） |
| --- | --- |
| ≤ 0.002（Phase XIII 旧 B1） | **J ≥ 498**（旧轮只跑到 200） |
| ≤ 0.001 | J ≥ 998 |
| ≤ 5e-4 | J ≥ 1998，但已超出本轮仪器的可用范围（见 §3） |

`P13-O1` **关闭**。Phase XIII 的 **E2 未关闭**判定保持原样（R6）：本轮是新一轮、新判据形式，
不是把旧判据改成能过。

## 3 如实披露（运行后追加，`registered_before_run: false`，**零项检验地位**，不影响 §1 判定）

- **D-1 绝对残差 ≠ 相对精度。** 注册的 XIV-1 是**绝对**判据，所以 E1 是在绝对意义下挣到的。
  把残差除以 `δ` 本身（顺序 logistic / probit / gumbel），相对误差随 `J` 增大：`J=10` 为
  **0.14 / 0.13 / 0.16%**，`J=400` 为 **0.21 / 3.04 / 4.04%**，`J=800` 达 **13.52 / 11.81 / 3.91%**。
  因此**可主张**"律在本仪器自报的绝对分辨率内成立"，**不可主张**"律在 `J → ∞` 的相对意义下被验证"——
  那正是被绝对判据掩盖的方向。
- **D-2 全局容差救下了 5 个格。** 判据用 `3·max_J s(J)`（P14-A1 原文如此）。若逐格改用
  `3·s(J)`，**5/21 格**会失败（logistic `J = 40, 200, 400` 与 gumbel `J = 100, 200`，
  它们的 `s(J)` 极小甚至为 0，而残差仍是 1e-5 量级）。注册规则是全局取最大值，我没有事后改动它；
  这条只作为"判据强度依赖取 max 而非逐格"的**能力缺口**登记（**X-44**，规则 **R8** 同一类）。
- **D-3 `s(J) = 0` 的格是仪器构造造成的。** logistic 有 3 格在 `n = 20001` 与 `n = 40001` 上
  给出**逐位相同**的 `β*`。位移为 0 不等于无误差——它是二分落在同一浮点象限的假象（X-29 同类）。
- **D-4 本轮只测了 `k = 2`。** 选择它是 **P14-A3** 的锚定要求（与上一轮失败的那次测量同仪器同 `k`）。
  `δ(J)` 与 `k` 无关是**代数事实**（§2 的 κ 消去），但**未在 `k = 3, 4` 上实测** ⇒ 登记为 **P14-O1**。
- **D-5 仪器可用范围由 §1 的容差反推**：`δ ≳ 5.5e-4` 可分辨 ⇒ `J ≲ 1816`；
  再大的 `J` 需要更细网格或更紧二分，属新一轮（预注册后再跑）。
