## 0 问题

Phase IV 的大结论是「**形式不变、常数随分布**」。但那三个"基底"都是**同一类系统**
（标量随机单元：可加驱动 + 加性单调噪声）。本轮把间隙门槛律 `β·Δ ≥ κ` 放到
**结构不同的三个合成系统**上，问一个可被杀掉的问题：

> **不变的是"律的形式"，还是只有"门槛由驱动间隙决定"这件事？**

| 系统 | 决策生成方式 | 与 S1 的结构性差别 | 噪声标度 |
| --- | --- | --- | --- |
| **S1 加性标量单元** | `p = F(β(T(x) − θ))` | ——（参照系，Phase IV/V 的系统） | 加性，尺度由 `F` 的分位差给出 |
| **S2 计数发放系统** | `N ~ Poisson(Λ = ρ·T(x))`，`p = P(N ≥ m)`，`m` 为**整数**阈值 | 噪声来自**计数**，SD ∝ √Λ ⇒ 噪声随工作点增长；阈值离散 | `ρ` 是发放率增益 |
| **S3 级联合取系统** | 每通道独立判决后 **概率相乘**：`p = ∏_i F(β(x_i − θ))` | 合取发生在**判决之后**（可靠性串联），不是驱动聚合 | 每通道各自加噪 |

## 1 预测（先写死，含可杀形式）

**P6-S1（参照）**：`β* = κ_F(α)/Δ`，且 `log β*` 对 `log Δ` 的斜率 = **−1**。
网格/基底与 `PHASE5_RESULTS.md` §2 相同（3 基底 × 3 t-norm × n∈{2,3,4}），
判据：**与已提交 V2 读数逐格相同（差 ≤ 1e-3）**。不过 ⇒ 整节 NOT VALID（说明本轮仪器与 Phase V 不可比）。

**P6-S2（计数系统）**：由 `b − a ≥ z_{1−α}(√a + √b)`（`a = ρ·T_lo`、`b = ρ·T_hi`）解出

```
ρ*(Δ)  ≈  z_{1−α}² (√T_lo + √T_hi)² / (T_hi − T_lo)²        Δ = T_hi − T_lo
```

⇒ 在 `one_weak` 退化族（`T_lo = s, T_hi = 1`）上：
① **斜率** `d log ρ*/d log Δ` = **−2**，容差 **±0.15**；
② ~~数值 `ρ*` 与上式（`z_{0.95} = 1.6449`）的**相对误差 ≤ 5%**~~ → **P6-A5/A6 替换为无常数的渐近形式**：
   比值 `ρ*_exact / ρ*_approx → 1`，具体判据为
   **(a)** 相对误差随 `Λ_hi` **单调不增**；**(b)** 族内最大 `Λ` 处的误差 ≤ 最小 `Λ` 处误差的 **1/2**
   （跨约 20 倍 `Λ` 区间要求至少半个 `√Λ` 量级的衰减，**不引入任何待调常数**）。
   理由：正态近似自身误差阶为 `O(Λ^{-1/2})`，任何**绝对**百分比界（5%、2%）都需一个没有根据的常数；
③ 离散性检查：`ρ*(Δ)` 曲线对 `Δ` **单调不增**，且整数阈值 `m*` 随 `ρ` 增大而增大（否则判据①无意义）。

**P6-S3（级联系统）**：合取在判决之后 ⇒ 常数被**可靠性折扣**改写。令
`α_f = 1 − (1−α)^{1/n}`、`α_s = α / (1−α)^{(n−1)/n}`，预测

```
β*(n)  =  q_{1−α_f}(F) − q_{α_s}(F)          （硬 AND，逐 n）
```

判据：数值 `β*(n)` 与上式**绝对差 ≤ 0.05**（n = 2,3,4；logistic 与 probit）；
且退化族上 `d log β*/d log(1−s)` = **−1**（容差 ±0.15，与 S2 的 −2 构成可分辨对照）。

## 2 主张口径（三条互斥出口，按序取第一条成立的）

| 出口 | 条件 | 允许写成 |
| --- | --- | --- |
| **O-INVARIANT** | P6-S1 ∧ S2 ∧ S3 的斜率判据全部落在 `−1 ± 0.15` | "律的形式跨系统不变"（Phase IV 主张升级为跨系统） |
| **O-FORM-CHANGES** | S1 与 S3 的斜率同为 −1，而 S2 的斜率 ≈ −2 | **"跨系统不变的只有'门槛由驱动间隙决定'；形式（幂指数）随噪声的标度方式改变"** ⇒ Phase IV §4 的大结论须收窄为"同一类加性噪声单元内形式不变" |
| **O-REFUTED** | 任一系统的存在性判据与自身预测矛盾（不是斜率而是符号/单调性） | 间隙律在该系统**不成立**，登记为否证 |

## 5 运行前更正登记（`registered_before_run: true`；判据与容差一律不改）

| 编号 | 内容 | 性质 |

| **P6-A1** | §1 的 P6-S3 常数 `α_s = α/(1−α)^{(n−1)/n}` 是**按"一个通道退化"（one_weak）推导**的特例。一般形式应为：静默构型中仍满值的通道数 `k`、退化通道数 `m`（`k+m=n`），则 `α_s = (α/(1−α)^{k/n})^{1/m}`。据此**硬 AND**（`k=1, m=n−1`）与 **all_weak**（`k=0, m=n` ⇒ `α_s = α^{1/n}`）的预测常数与原文不同；`α_f = 1−(1−α)^{1/n}` 与 `gap` 定义不变 | 推导补全，运行前修正 |
