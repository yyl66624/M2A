# M2A Phase II 预注册：三个最小实验（E1 / E1b / E2）

> 日期：2026-10-17 ｜ 状态 **v1（先于运行写定）** ｜ 范围：合成/仿真，本机 CPU
> 依据：Phase I′ 的五条初级结论（`literature/PRELIMINARY_CONCLUSIONS_V2.md`）与 O-03′

---

## 0 共同纪律

1. 每个实验先过**门控自检**（确定性、已知答案、阴性对照），未过不得运行；
2. 指标、阈值、样本量、失败标准**先写死**；看到结果后不得改；
3. 三出口：**SUPPORTED / REFUTED / UNDECIDABLE**；负结果原样登记；
4. 全部为**合成**实验，不涉及真实数据、动物/人体、付费算力或大模型训练。

**统一记号**：`σ(z)=1/(1+e^{−z})`；每格 20,000 次伯努利抽签（固定种子 0–9 共 10 组，报告均值与组间 SD）。

## 1 E1：合取（K4）——"单路不足、双路超加性"

**假设 H1**：在合取架构下，单路输入几乎不产生行动，双路同时输入产生行动；交互项显著为正。

| 架构 | 生成式 |
| --- | --- |
| `single` | `p = σ(β(x₁ − θ))`（只有通道 1） |
| `and` | `p = σ(β(x₁·x₂ − θ))`（乘性合取） |
| `or` | `p = σ(β(x₁ + x₂ − θ))`（加性/析取） |

参数：`β = 6`，`θ = 0.5`；输入 `x ∈ {0,1}²`，另加"噪声"条件：`x` 以 `ε = 0.1` 概率翻转。

**指标**：`P(a=1 | x₁x₂)`、交互 `I = P(11) − P(10) − P(01) + P(00)`、单路充分性 `max(P(10), P(01))`。

| 预注册判据 | 阈值 |
| --- | --- |
| `and` 的单路率 | **< 0.05** |
| `and` 的联合率 | **> 0.90** |
| `and` 的交互 `I` | **> 0.80** |
| `or` 的单路率 | **> 0.90**（阴性对照：同样输入下不应"单路不足"） |
| `or` 的交互 `I` | **< 0.05** |

**判定**：若 `and` 三条件全中且 `or` 两条件全中 ⇒ **SUPPORTED**；`and` 任一条不中 ⇒ **REFUTED**（"合取=单路不足+超加性"在本模型类不成立）；`or` 出现单路不足 ⇒ **UNDECIDABLE**（仪器问题）。

## 2 E1b：触发 vs 门（K1 vs K2/K11 的签名）

**假设 H1b**：触发是**单向**的（控制量增大只会提高行动率）；门是**双向**的（改变极性可反转符号）；约束是**饱和**的（过阈后不再增加）。

| 机制 | 生成式 | 控制量 |
| --- | --- | --- |
| `trigger` | `p = σ(β(x − θ))` | `x ∈ [0,1]` |
| `gate` | `p = σ(β(g·x − θ))`，`g ∈ {+1,−1}` | `x`，极性 `g` |
| `constraint` | `p = min(σ(β(x − θ)), c)`，`c = 0.6` | `x` |

**指标**：行动率曲线 `p(x)` 的单调性（Spearman ρ）、符号翻转（是否存在 `x₁<x₂` 使 `p(x₂)<p(x₁)` 超过 0.05）、饱和（`x > θ+1` 后斜率 < 0.02）。

| 预注册判据 | 阈值 |
| --- | --- |
| `trigger`：ρ | **= 1**（严格单调），且无翻转 |
| `gate`：`g=+1` 与 `g=−1` | 两条曲线**符号相反**（ρ=+1 与 ρ=−1） |
| `constraint`：饱和段斜率 | **< 0.02** |

**判定**：三条全中 ⇒ **SUPPORTED**；`trigger` 出现翻转或 `gate` 不翻转 ⇒ **REFUTED**；仅饱和未达 ⇒ **UNDECIDABLE**。

## 3 E2：省略的 S/C 拆分（O-03′）

**假设 H2**：S 层（选择性不响应）不需要表征；C 层（反事实可及性）需要。可操作判据是**可及性敏感度**：

```
固定"实际输入与结果"，只改变"被跳过选项是否可用"，看行为/价值是否改变。
S-only 代理：状态 = 当前输入（不含可用性集合）⇒ 敏感度应为 0。
S+C 代理：状态 = 当前输入 + 可用性集合 ⇒ 敏感度应显著 > 0。
```

**两个代理**（同一决策规则：`max(v) > θ` 则按 softmax 选择，否则弃权）：
- `S_only`：状态 `s = x`（当前观测），不含"可用集合"；
- `S_plus_C`：状态 `s = (x, A)`，`A` 为可用动作集合。

用**表格 Q-learning**（`α=0.1`，`γ=0.9`，`ε` 从 0.3 线性降到 0.02，20,000 步）学习，然后在两类探针上测量：

| 探针 | 设计 | 指标 |
| --- | --- | --- |
| **S 层** | 双动作可用、`max(v) < θ` | 弃权率（两者都应 > 0.30） |
| **C 层** | 匹配对：`{A=0.9,B=0.5}` vs `{A=0.9}`（A 的实际选择与结果相同） | **可及性敏感度** `Δ = |Q(s₁,a) − Q(s₂,a)|` |

| 预注册判据 | 阈值 |
| --- | --- |
| 两者弃权率 | **> 0.30**（S 层成立） |
| `S_only` 的 `Δ` | **< 0.05** |
| `S_plus_C` 的 `Δ` | **> 0.30** |

### 3.1 运行前修正（P2-A1，2026-10-17，**在任何格被读取之前**）

原稿的探针对写成 `{A=0.9,B=0.1}`，但阈值要求 `Δ > 0.30`；而按设计 `Δ = γ·v_B = 0.9×0.1 = 0.09`，
**原稿自身不可能通过**。这是预注册的内部不一致，**不是**结果驱动的改动：

- 探针对改为 `{A=0.9,B=0.5}` ⇒ 手算 `Δ = γ·0.5 = 0.45`，与阈值 0.30 相容；
- 环境值改为**固定** `[0.9, 0.5]`（可用性随机）：随机值会让 `(max, mask)` 不足以决定未来，
  使 `Q` 成为未观测备选项的均值，手算值不尖锐（`C4` 门控因此一度报 FAIL）。

两处改动均在**首次运行之前**写入，并保留原稿痕迹。

### 3.2 运行前修正（P2-A2）：动作成本与两个值域

原稿的决策规则是"`max(v) > θ` 则行动，否则弃权"，但在**没有行动成本**的模型里弃权永远不是最优
⇒ "S 层弃权率 > 0.30" 这条判据无法被满足，实验会因设计而非现象失败。

**修正**（仍在首次运行之前）：给行动加成本 `c = 0.1`，净收益 `= v − c`；环境取两个**固定值域**：

| 值域 | 值 | 净收益 | 设计用途 |
| --- | --- | --- | --- |
| 高（80%） | `[0.9, 0.5]` | `+0.8 / +0.4` | C 层探针（可及性敏感度） |
| 低（20%） | `[0.05, 0.1]` | `−0.05 / 0.0` | S 层探针（弃权应为最优） |

**手算**：`Q(A|{A}) = 0.8`；`Q(A|{A,B}) = 0.8 + γ·0.4 = 1.16` ⇒ `Δ = 0.36`（阈值 0.30 相容）。
`C4` 门控相应改为检查 `Δ ≈ 0.36`，`C6` 改为检查 `Q(A|仅 A) = 0.8`。

**判定**：三者全中 ⇒ **SUPPORTED**（C 层需要表征）；`S_only` 的 `Δ` 显著 > 0.05 ⇒ **REFUTED**（无需表征即可产生可及性敏感——O-03′ 需改写）；弃权率不足 ⇒ **UNDECIDABLE**。
