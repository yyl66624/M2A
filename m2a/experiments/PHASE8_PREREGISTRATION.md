## 0 问题（一句话）

Phase VI 的 S2 实测 `d log ρ*/d log Δ` = **−2.2745**（正态近似给 −2），且近似误差**不随 Λ 单调下降**（锯齿）。
问：锯齿是**整数阈值离散性**造成的、可由一个显式的**平滑刻画**消除，还是计数噪声本身就有 −2 以外的指数？

## 1 推导（先写死，作为待检验主张）

对 `N ~ Pois(Λ)`，用上/下侧分位的 Edgeworth 一阶校正（偏度 `Λ^{-1/2}`，系数
`c₁ = (z² − 1)/3`，`z = z_{1−α} = 1.6448536`）：

```
m_lo(a) = a + z√a + c₁            （使 P(N ≥ m | a) ≤ α 的最小门槛）
m_hi(b) = b − z√b − c₁            （使 P(N ≥ m | b) ≥ 1−α 的最大门槛）
平滑可行性： m_hi(b) ≥ m_lo(a)  ⇔  b − a ≥ z(√a + √b) + 2c₁
代入 a = ρs、b = ρ（Δ = 1 − s）⇒ 关于 √ρ 的一元二次，取正根：

√ρ*_smooth = [ z(1+√s) + sqrt( z²(1+√s)² + 8 c₁ Δ ) ] / (2Δ)
ρ*_smooth(s) = ( 上式 )²
```

**结构性断言**：`2c₁` 项使平滑曲线**不再是齐次幂律**，但在 `Δ → 0`（大 Λ）端相对可忽略 ⇒ 指数回到 −2；
而锯齿来自"必须存在**整数** m"这一步，其幅度由 `dρ/dm ≈ ρ/(√Λ · z)` 量级给出。
