## 0 三条近似旋钮，一条比一条狠

门槛判据 `∃θ：F(β(1−θ))^k ≥ 1−α 且 F(β(lo−θ))·F(β(1−θ))^{k−1} ≤ α` 里，`∃`（取 max）是**非光滑**的：
把节点加密一半，`max` 可能落在同一个节点上 ⇒ 读数**逐位不变**，而真实偏差并未变小。这正是
`L_density = 0` 与 `L_trunc = 0` 同时出现、而两个 `k` 的读数仍不等（X-53）的机制候选。

| 旋钮 | 定义 | 它单独能看见什么 |
| --- | --- | --- |
| **密度** | `n : 20001 → 40001`（间距减半） | 间距一阶效应 |
| **区间** | `h : 1.0 → 2.0`（外扩一倍） | 截断效应（Phase XVII 已实测：与密度同量级、且由间距主导） |
| **平移**（本轮新增） | `σ : 0 → 0.5`（整节点集沿 θ 轴平移 `σ·dθ`，**不改 `n`、不改区间**） | **aliasing**：间距与区间都不变、只换节点落点 |

主读数取三条都"更不近似"的那一配置，各层的位移用"主读数 vs 只回退该一条旋钮"的差定义：

```
primary           := (h=2.0, n=40001, σ=0.5)
L_density(J; k)   := |δ̂(primary) − δ̂(h=2.0, n=20001, σ=0.5)|
L_trunc  (J; k)   := |δ̂(primary) − δ̂(h=1.0, n=40001, σ=0.5)|
L_stag   (J; k)   := |δ̂(primary) − δ̂(h=2.0, n=40001, σ=0.0)|
每格三层合计  L3(J; k) := L_density + L_trunc + L_stag
本轮容差      T₁₈      := 3 · max over all (kind, k, J) of L3(J; k)
```

`σ = 0` 时必须与 Phase XVII 的对应读数**逐位相同**（新增代码只允许平移，不允许改动其它任何东西）。

## 2 为什么不用"全局地板"或"排除零界格"（R14 的落地方式，先于读数选定）

R14 要求零值处理在注册时就定。三种可选口径：

| 口径 | 后果 | 本轮取舍 |
| --- | --- | --- |
| (a) 界取全表最大位移（全局地板） | 每格都按"最坏格"计，**比真实偏差更松** ⇒ E1 变容易 | **不用**：本轮的目标恰恰是"能不能收紧"，用地板等于放水 |
| (b) 三层全盲的格排除出分母 | 样本变小，且"排除"本身就假设了"盲 ⇒ 无信息" | **不用**：Phase XIV 的 X-44 已登记过全局 max 的问题 |
| (c) 零界 + 读数不等 ⇒ **FAIL** | 保守；且若第三条旋钮确实看见 aliasing，界自然非零、无需放水即可判 | **采用**（即 C18-3 的字面形式） |

附带一条**诊断即结论**的登记：若 `L_stag` 全表为 0（三条旋钮都看不见误差），则本轮无法为跨 `k` 差异提供任何
非零界，C18-3 将按 (c) 失败 ⇒ 如实登记为"该仪器的读数不一致**不可由任何单条离散化旋钮界定**"，
这是比 XVI/XVII 更强的负结论，也是 `P14-O1` 的终点（不再另立一轮去加第四条旋钮）。
