## 1 系统

**S4(k, m)**：k 个**级**串联，每级是 m 通道的**硬合取**（乘积 t-norm），共享一个阈值 θ：

```
p(x) = ∏_{i=1..k} F( β · ( ∏_{j=1..m} x_ij  −  θ ) ),     x ∈ {0,1}^{k·m}
```

即"先在级内做判决前聚合，再在级间做判决后串联"——正是 Phase VI 只有两个端点（S1 纯聚合 / S3 纯串联）
时无法区分的那个**中间结构**。

## 2 预测（三种构型，公式先写死）

记 `q_p = q_p(F)` 为分位函数，`α = 0.05`。

| 构型 | 点火端 | 静默端 | 预测门槛 |
| --- | --- | --- | --- |
| **C-hard** | 全通道 1（每级 drive 1） | **恰一级失效**（其 drive 0），其余级全 1 | `β*(k) = q_{(1−α)^{1/k}} − q_{ α / (1−α)^{(k−1)/k} }` |
| **C-graded** | 全通道 1 | **穷举下的最大静默构型**：恰一级的一个通道降到 s（该级 drive s），其余级全 1 | `β*(k,s) = [ q_{(1−α)^{1/k}} − q_{ α/(1−α)^{(k−1)/k} } ] / (1 − s)` |
| **C-reduce** | —— | —— | `k=1` 必须退回 `κ_F(α) = q_{1−α} − q_α`（Phase IV/V）；`m=1` 必须退回 Phase VI 的 S3 式 `q_{1−α_f} − q_{α_s}` |

**本轮的主张不是"β* 有某个值"，而是一条分类判据**：

> **P7-A**：C-hard 的 `β*` **与 m 无关**（m=1,2,3 给出同一个数），只随级数 k 变化。
> 含义：门槛常数由**判决后的串联级数**携带；**判决前的合取宽度**只通过驱动间隙 `Δ` 进入（Phase V 的结论），
> 在硬 AND（Δ=1）下不进入常数。

## 3 网格与判据

`k ∈ {1,2,3}` × `m ∈ {1,2,3}` × `s ∈ {0.5, 0.75}` × `F ∈ {logistic, probit}`；
仪器为**穷举全部 2^{k·m} 个输入构型**取静默端最大值（不是代入 §2 的假设构型），θ 网格按 R5 推导定密度。

| 编号 | 判据 | 容差 |
| --- | --- | --- |
| **V7-1** | C-hard：数值 `β*(k,m)` ↔ `q_{(1−α)^{1/k}} − q_{α/(1−α)^{(k−1)/k}}` | 绝对 ≤ **0.05** |
| **V7-2（P7-A）** | 同一 (k, F) 下 m=1,2,3 的数值差 max − min | ≤ **0.005**（预测为**恒等**，故用紧容差） |
| **V7-3** | C-graded：数值 ↔ 含 `(1−s)` 的完整式，且斜率 `d log β*/d log(1−s)` = −1 | 绝对 ≤ 0.05；斜率 ± 0.15 |
| **V7-4** | 还原 (a)：`k=1` 的 C-hard ↔ Phase IV/V 的 `κ_F`（k=1 时"恰一级失效"与"其余全失效"是同一件事，还原是严格的） | ≤ 0.005 |
| **V7-4b** | 还原 (b) **已按 P7-A2 改为方向性诊断，不再是相等判据**：`m=1` 的 S4 数值须**严格大于** Phase VI 的 S3 常数，且差值可由"绑定静默构型是 r=1 而非 r=k−1"完全解释（逐项给出两个 `a_s` 的代入值与差） | 方向必须为 `S4 > S3`；等式核验到 ≤ 1e-9 |
| **V7-5** | 静默端构型归属：穷举得到的**最大静默概率所在构型**，其"失效级数"必须恰为 1（C-hard） | 全部格 |
