## 0 问题

Phase IX 的"聚合免疫"是在**硬字母表** `{s,1}` 上证的（`X-25` 已划界：软输入不主张成立）。
把每级通道驱动换成连续值 `x ∈ [0,1]` 之后，"失效"必须重新定义为**带**：`T(x) ≤ τ`。
问：门槛常数是依赖带边界 `τ`，还是依赖聚合器在带内**实际能达到**的上确界？

### 1 推导

系统 `S5(k,m,τ)`：`k` 级、每级 `m` 个通道，驱动 `x_i ∈ [0,1]`，配置权重 `∏_级 F(β(d_j − θ))`，
`d_j = T(x^{(j)})`（沿用 Phase VII/IX 的**最坏配置**口径：对可达驱动取上确界，而非对 `x` 积分——
两者的差别登记为 `P11-F1`，见 §6）。

- **发放**：所有级取到可达的最大驱动 `1` ⇒ `p_fire = F(β(1−θ))^k`，要求 `≥ 1−α`。
- **静默**：至少一级落入带 `d ≤ τ`。因 `F` 严格增，带上确界只取决于**可达集** `R(T,m) = {T(x) : x ∈ [0,1]^m}`：

```
L_τ := sup( R(T,m) ∩ [0, τ] )                                (◆◆)
最坏静默配置 = 一级在 L_τ、其余 k−1 级在 1
⇒  β*(T,k,m,τ) = ( q_φ − q_ψ ) / ( 1 − L_τ ),  φ=(1−α)^{1/k}, ψ=α/(1−α)^{(k−1)/k}
```

**主张 1（τ-免疫 ⟺ 满射性）** 若 `T` 在 `[0,1]^m` 上连续且 `T(τ,1,...,1) = τ`（product / min / Łukasiewicz
都满足），则 `L_τ = τ` ⇒ 常数**只依赖 τ**，`m` 与 `T` 全不进——这是 Phase IX 免疫性在软输入下的**真推广**。

**主张 2（不连续聚合器拆开两个假设）** 取两个"带内不可达"的聚合器：
- **nilpotent minimum**：`T_nm(x) = min(x)` 若 `min(x) > 0.5`，否则 `0` ⇒ `R = {0} ∪ (0.5,1]`
  ⇒ `τ = 0.3` 时 `L_τ = 0`，预测 `β* = (q_φ−q_ψ)/1`，比"朴素 τ 代入"的 `(q_φ−q_ψ)/0.7` **小 2.33 倍**；
  `τ = 0.55` 时 `L_τ = 0.55`（可达）⇒ 与朴素一致。
- **stepped min**（把 `min` 下取整到格 `h=0.25`）：`τ = 0.3` 时 `L_τ = 0.25` ⇒ 预测比朴素值**小 6.7%**。
⇒ 若仪器读数跟随 (◆◆) 而不跟随朴素 `τ`，则"常数依赖可达上确界"成立；反之主张 1/2 被否证。
   两个假设（"依赖 τ" vs "依赖 L_τ"）在 `τ=0.3` 处可分度为 **133%** 与 **6.7%** ⇒ 判据不是同义反复。

**主张 3（B 组，P9-O1）** `k` 级自由阈值的可行条件仍是逐级比值不动点
`P(ρ) = ∏_i U_i(ρ)`，`ρ₀·P(ρ₀) = α`，存在窗口 ⟺ `P(ρ₀) ≥ 1−α`。`k=3` 且各级同构时最优必对称
⇒ 自由阈值不改门槛；`k=3` 且 `τ_i` 异构（本轮用 `τ` 带而非 `s`，异构取 `τ ∈ {0.3,0.55,0.7}` 的三元组）
时严格占优。
