## 0 为什么不能继续用"我算出来的常数"

Phase X 的运行后追加（X-28）说：精确 Poisson **连续**分位相对 `λ + z√λ` 的偏移实测 ≈ **−0.212/侧**，
与 `Cornish–Fisher (z²−1)/6 = +0.284` 减半格点 `0.5` 相符，而 Phase VIII 用的 `+0.5685` 符号数值皆错。
但**这里有一处我不能自证的口径问题**：Phase VI 的精确仪器本来就是**在整数门槛上**枚举尾概率的，
所以"半格点"可能已经被精确仪器**吸收**了——若再减一次 `0.5` 就是重复计数。
连续分位、整数门槛、`≥` 与 `>` 的取整方向三者混在一起，**靠争论定不下来**。

⇒ 本轮把 `e₀` 当**一个自由参数**，用已提交的精确仪器读数**反推**它，再问在该常数下指数是否为 −2。

## 1 记号

沿用 Phase VIII/X：平滑可行性 `Δρ − B(s)√ρ − e₀ − e₁/√ρ = 0`，`Δ = 1−s`，`B = z(1+√s)`，
`R = √ρ`；`e₁ = 0` 时正根闭式 `R± = [B ± √(B² + 4Δe₀)]/(2Δ)`。
`e₀ < 0` 且 `B² + 4Δe₀ > 0` 时有**两个正根**：可行集为 `[0,R₋] ∪ [R₊,∞)`，`R₋` 那一支即
"截断式在低速率端宣称可行"的可疑分支。
精确侧：`ρ*_exact(s) = p8_smooth.rho_exact(s)`（Phase VI 仪器，未改动）。
