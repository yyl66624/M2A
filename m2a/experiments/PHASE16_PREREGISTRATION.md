## 1 为什么这件事可以判

Phase XIV 的推导里 `κ` 消掉了：

```
β*(k, lo) = κ(k)/(1 − lo)   ⇒   δ(J) = 1 − (1 − L)/(1 − lo_J) = 1/(J+2)      （与 k 无关）
```

所以**数值仪器在 `k = 3, 4` 上偏离 `1/(J+2)` 的部分，只能是离散化偏差**，不可能是定律本身。
本轮因此有两个独立的问题要问：

| 问题 | 判据 | 若失败说明什么 |
| --- | --- | --- |
| 律在 `k = 3, 4` 上是否仍落在仪器自报的绝对分辨率内？ | **C1** | 存在未建模的 `k` 依赖（例如 θ 网格与串联结构的耦合）⇒ 必须再立一轮 |
| 同一格点在 `k = 2`（已提交）与 `k = 3/4`（本轮）两套读数是否互相一致？ | **C4** | 两个 `k` 的读数差超过两台仪器各自加密位移之和 ⇒ 读数不可比，Phase XIV 的锚定链条有隐含 `k` 依赖 |
