## 2 内容：一条**组合律**，而不是两个端点的类比

S4(k,m) 的门槛把 Phase V（判决前聚合）与 Phase VI（判决后串联）合成同一式子：

```
β*(k, m, s)  =  [ q_{(1−α)^{1/k}}  −  q_{ α / (1−α)^{(k−1)/k} } ]  /  (1 − s)
                 ^^^^^^^^^^^^^^^^ 可靠性折扣：只数"级"的个数      ^^^^^^ 聚合宽度只通过间隙进入
```

* **k=1** 时折扣消失，退回 `κ_F(α)/(1−s)` = Phase V 的间隙门槛律（还原核验到 1e-4）；
* **m 完全不出现在常数里**（散布 0.0）：在硬合取下，"一级里有几个通道"不改变门槛，
  改变门槛的只有"有几级串联"和"驱动间隙被压缩了多少"；
* **斜率 −1** 在两个基底、三个 k、三个 m 上全部复现 ⇒ 分母 `(1−s)` 是**乘性**的，与折扣项可分离。

⇒ 这条律把 Phase VI 留下的"判决前 vs 判决后"从**分类**升级为**可计算的组合**：
两者作用在式的不同位置（分母的间隙 vs 分子的折扣），因此可以叠加并预测混合拓扑。

## 3 P7-A2：本轮回写了 Phase VI 的一条**解释**（不改动其判定）

Phase VI 的 S3 把静默端取为 `channels(n,'hard') = [1,0,…,0]`，即 **r = n−1 级失效**。
而 `p_silent = F(u)^{k−r}F(v)^{r}` 在 `v < u` 时随 r **递减** ⇒ 那是**最省力**的失效构型，不是绑定构型。
门控 H4 已把 S3 的已提交预测值与该公式在 r=n−1 下核到 **≤1e-9**（即 S3 内部是自洽的），
但真实的门槛要求 r=1：

| 基底 | k | Phase VI S3（r=k−1） | Phase VII S4（r=1，绑定） | 差 |
| --- | --- | --- | --- | --- |
| logistic | 2 | 6.5687 | 6.5687 | **+0.0000**（k=2 时 r=k−1=1，两者 coincidentally 同一构型） |
| logistic | 3 | 5.2955 | **6.9693** | **+1.6738** |
| probit | 3 | 2.8752 | **3.7502** | **+0.8750** |

**后果**：Phase VI 记录的"判决后串联的门槛随通道数**下降**（6.5687→5.2955→4.8835）"
是**非绑定构型的产物**；按绑定构型，门槛随串联级数**上升**（5.889→6.5687→6.9693），
方向与可靠性折扣的直觉一致。
Phase VI 的注册判定**不变**（其"数值与解析一致 ≤0.0015"说的是同一个错误构型下的自洽，仍然成立）；
候选创新点 I6 的措辞**作废**，由本节的组合律取代（登记于负面日志 X-16）。
