## 0 本轮唯一的主张与为什么它不需要 A1

Phase V-c 的结构性缺陷：四个出口都以 A1（全臂 DP 忠实）为必要条件，而
**当某臂的行为策略内生时，均值场算子有多个不动点，DP 忠实性原理上不可声明** ⇒ 出口永远无法触发。
本轮因此把"DP 忠实"从主判据里**移除**，而不是放宽容差：

> **主判据 D1**：在**从未使用过的种子**上，学习器读数等于由环境生成过程先验推出的闭式。

闭式（与 Phase V 后验分解同一表达式，此处**升级为待检主张**）：

```
先验  P(B可用 | max=0.9) = (1/4)/(1/4+3/8) = 2/5
后验  p_c = (2/5)·q_c / ((2/5)·q_c + (3/5)·(1−q_c)) ,  q_1 = q, q_0 = 1−q
覆盖  w(p) = (p/3) / (p/3 + (1−p)/2)                    （第一步外生均匀，|avail| = 3 或 2）
Δ_closed(q) = γ (v_B − c) · ( w(p_1) − w(p_0) ) = 0.36 · ( w(p_1) − w(p_0) )
```
