## 1 A 组（P12-O2）：把"连续分位 vs 整数门槛"的口径差写成**可判别数**

X-35 的根因是我把连续分位的偏移搬给了整数门槛仪器。本轮不靠反思，而靠一条数值对照：
对同一 `λ`，令

```
C(λ) = q_cont(λ) − (λ + z√λ)        （CDF 线性插值的 (1−α) 分位偏移；Phase X 实测 ≈ −0.212）
D(λ) = m_ge(λ) − (λ + z√λ)          （"最小的 m 使 P(N ≥ m | λ) ≤ α"，即仪器真正用的对象）
```

**主张 A**：`D(λ) − C(λ) → +0.5`（一个格点）当 `λ → ∞`，且
`C(λ) + 0.5 ≈` Phase XII 反推得到的**每侧**常数 `0.53/2 = 0.265`。
⇒ 若成立，则 Phase X 的 −0.212 与 Phase XII 的 +0.284 **不是矛盾而是同一点的两种口径**，
X-35 的解释闭合；若不成立，则 Phase XII 的常数反推仍需另查。

| 编号 | 内容 | 容差 |
| --- | --- | --- |
| **A1** | `D(λ) − C(λ)` 在 `λ ∈ {30,100,400,1600,6400}` 上落在 `0.5 ±` **0.02** | 0.02（格点半宽的 4×，运行前写死） |
| **A2** | `C(λ)` 随 `λ` 的**漂移幅度**（max − min）≤ **0.01** ⇒ 它是 `O(1)` 项而非 `O(√λ)` 项 | 0.01 |
| **A3** | `C(λ) + 0.5` 与 Phase XII 的每侧拟合值 `0.53/2` 之差 ≤ **0.05** | 0.05（= A1 带宽 + 拟合平坦度 X-37 的 0.04） |

## 2 B 组（P11-O2）：`L ∉ R`（上确界取不到）时定理的退化分支

构造一个可达集**开区间上端**的聚合器：`R_J = {0, 1} ∪ {0.5 − 0.5/(j+1) : j = 0..J}` ⇒
`sup(R_J ∩ [0,0.5]) = 0.5 ∉ R_J`（有限 `J` 时只逼近）。两种判据口径：

- **闭包口径**：`drive_lo = 0.5`（定理里用 `L := sup`）；
- **取到口径**：`drive_lo = max(R_J ∩ [0,0.5]) = 0.5 − 0.5/(J+1)`（有限集合真正取得的最大元）。

| 编号 | 内容 | 容差 |
| --- | --- | --- |
| **B1** | 取到口径的 `β*(J)` 随 `J` **单调不增**且收敛到闭包口径值：`|β*(J) − β*_closure| ≤ 0.002·β*` 对 `J ≥ 40` | 0.002（同 XA1 的量级，由 `dθ/gap` 推） |
| **B2** | 在 `β = β*_closure` 这一点上，取到口径**不可行**（严格未 attainment）⇒ 判据必须写成 `silent ≤ α` 于闭包上，否则边界情形漏判 | 布尔判据，无容差 |
| **B3** | 定理的常数形式在两种口径下都是 `(q_φ − q_ψ)/(1 − L)`，只换 `L` 的定义 ⇒ `β*_closure` 与 `(q_φ − q_ψ)/0.5` 一致 | 相对 ≤ **0.002** |
