## 0 问题

Phase III 的三条律都在**同一基底**（logistic 单元）上验证。若它们只是 logistic 参数化的产物，
就不能作为"机制律"。Phase IV 在**三个独立基底**上重测，并检验：

> **跨基底不变性**：三条律的**形式**保持不变，只有**常数**随基底的噪声分布改变。

三个基底（同一结构、不同噪声分布 `F`）：

| 基底 | `F` | 5%/95% 分位 | 预测的合取阈值 `q_{0.95} − q_{0.05}` |
| --- | --- | --- | --- |
| **A logistic** | `σ` | ∓2.944 | **5.889** |
| **B probit（高斯）** | `Φ` | ∓1.645 | **3.290** |
| **C Gumbel** | `exp(−e^{−z})` | −1.097, +2.970 | **4.067** |

## 1 L1′：合取窗口的**一般形式**

对任意单调 CDF `F`、增益 `β`、阈值 `θ`：

```
p_single = F(β(0 − θ)) ≤ α        ⇔  θ ≥ −q_α / β
p_joint  = F(β(1 − θ)) ≥ 1 − α    ⇔  θ ≤ 1 − q_{1−α} / β
窗口存在 ⇔ β ≥ q_{1−α} − q_α
```

**检验**：每个基底扫 `β ∈ [1, 12]`（步长 0.01），求窗口是否存在的经验临界 β，
与上表预测常数比较（容差 **0.05**）；并在窗口内验证两条边界（MC，容差 0.005）。

| 判据 | 容差 |
| --- | --- |
| 三种基底的临界 β vs 预测 | **≤ 0.05** |
| 三个常数**互不相同**（说明不是同一拟合） | 两两差 > 0.5 |
| 每个基底窗口内的边界 MC vs α / 1−α | ≤ 0.005 |

---

## 2 L2′：门符号律的跨基底形式

`p(x; o) = F(β(x(2o−1) − θ))`。因 `F` 单调，`sign(∂p/∂x) = sign(2o−1)` **与 F 无关**。

| 判据 | 容差 |
| --- | --- |
| 三个基底、`o ∈ {0, 0.25, 0.75, 1}` 的符号全对 | 全部通过 |
| `o = 0.5` 时三基底均为常数 | max Δp < 1e-12 |

---

## 3 L3′：省略律的跨**估计器**形式

Phase III 用表格 Q-learning 得到 `Δ(q)=0.36(2q−1)`。该律是关于**后验证据**的，
应与估计器无关。Phase IV 用**两种独立估计器**重测：

1. `Q`：Phase III 的表格 Q-learning（覆盖采样）；
2. `Bayes`：直接对 `P(B|cue)` 做 Beta-Binomial 后验更新，再按 `γ(v_B−c)(2P(B|cue=1)−1)` 读出。

| 判据 | 容差 |
| --- | --- |
| 两种估计器在每个 q 的 `|Δ − 0.36(2q−1)|` | **≤ 0.03** |
| 两估计器的 Δ 差 | **≤ 0.03** |
| `q = 0.5` 时两者均 ≈ 0 | ≤ 0.01 |
