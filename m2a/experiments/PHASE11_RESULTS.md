## 1 P9-O2 的答复：`τ`-免疫是**满射性的推论**，不是聚合的性质

把 Phase VII/IX 的"最坏配置"口径延伸到连续驱动带 `T(x) ≤ τ` 后，常数是

```
β*(T,k,m,τ) = ( q_φ − q_ψ ) / ( 1 − L_τ ),      L_τ = sup( R(T,m) ∩ [0,τ] )        (◆◆)
```

- **满射聚合器**（product / min / Łuk，`R = [0,1]`）：`L_τ = τ` ⇒ 常数只依赖 `τ`，`m` 与 `T` 不进
  （XA2 极差恰为 0）——这是 Phase IX 免疫性的**真推广**，而非重复。
- **故意不满射的两个**：nilpotent minimum（`R = {0} ∪ (0.5,1]`）在 `τ=0.3` 时 `L_τ = 0`，
  stepped min（格 `h=0.25`）在 `τ=0.3` 时 `L_τ = 0.25`。仪器读数跟着 `L_τ` 走，
  偏离朴素 `τ` 代入 **30.0%** 与 **6.6%**。
  而在 `τ = 0.55`（nilpotent 可达）处两者重新一致 ⇒ 决定门槛的是**带的可达性**，不是带的宽度。

## 4 P9-O3 的答复：把 `L`-归约写成定理（硬/软字母表统一）

**定理（可达水平归约）** 设 `F` 严格增；`k` 级系统每级的可达驱动集为 `R ⊂ [0,1]` 且 `1 ∈ R`
（即 `T(1,…,1) = 1`）；发放要求所有级取 `1`；静默集合非空并由约束"至少一级的驱动 `≤ b`"给出
（硬字母表：`b` = 任意 `<1` 的可达值；软带：`b = τ`）。令

```
L := sup{ λ ∈ R : λ ≤ b }      （若上确界不在 R 中取到，则以 sup 值定义，见下方"退化"）
```

则最坏静默配置恰为"**一级在 `L`、其余 `k−1` 级在 `1`**"，且门槛

```
β* = ( q_{(1−α)^{1/k}} − q_{α/(1−α)^{(k−1)/k}} ) / ( 1 − L )
```

**证明**：任一静默配置至少有一级驱动 `d ≤ b`，又 `d ∈ R` ⇒ `d ≤ L` ⇒ 该级权重 `≤ F(β(L−θ))`；
其余各级权重 `≤ F(β(1−θ))`（因 `1` 是 `R` 的最大元且 `F` 增）。于是
`∏_j F(β(d_j−θ)) ≤ F(β(L−θ))·F(β(1−θ))^{k−1}`，且该上界由"一级 `L`、余级 `1`"的配置**取到**。
两侧同时取界（`F(β(1−θ))^k = 1−α`、`F(β(L−θ))F(β(1−θ))^{k−1} = α`）相减即得 `β*`。∎

**退化条件（须如实附带）**：若 `L ∉ R`（上确界取不到，如 stepped 型格点从下方逼近），
则静默侧是**上确界而非最大值**，判据 `silent ≤ α` 应在 `L` 的闭包上检验；
本轮所有不满射聚合器的 `L` 都在 `R` 中取到（XA3 逐位验证），故未触发该退化。

**统一性**：Phase IX 的"三条 t-norm 免疫"（`R ⊂ {s,1}` 型硬字母表，`L = s`）与
Phase XI 的"`τ`-免疫"（`R = [0,1]`，`L = τ`）是同一命题的两个 `R`；
两者的失效方式也相同：**换一个 `R`，就换一个常数**（`mean` 与 nilpotent 是两个反例）。
