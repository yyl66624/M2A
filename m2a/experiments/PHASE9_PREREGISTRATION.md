## 1 推导（运行前写死，判据由它生成）

### 1.1 记号

`α = 0.05`（`p5_mechanisms.ALPHA`），`φ = (1−α)^{1/k}`，`ψ = α/φ^{k−1}`，`q_p = F^{-1}(p)`。
一个系统有 `k` 级，每级 `m` 个通道，通道取值只两种：驱动 `1`、失效 `s`（`0 ≤ s ≤ 1`）。
级内聚合函数记 `T(x_1..x_m)`，要求 `T(1,..,1) = 1`。系统"发放"当且仅当**所有级都取到 1**；
"静默侧"是所有**至少有一级 < 1** 的配置里概率最大的那个（与 Phase VII 的枚举口径逐字相同）。
每级由驱动值映射成的**级水平集** `Λ(T,m,s) = {T(x) : x_i ∈ {s,1}}`，记

```
L(T,m,s) := max{ λ ∈ Λ(T,m,s) : λ < 1 }        （最大亚单位水平）
```

### 1.2 主张（本节的每一条都是可杀陈述）

**命题 1（水平优势）** 对任意 `θ`、任意 `β`，静默侧的最大值一定取自「恰有一级处于水平 `L`、
其余 `k−1` 级处于 1」的配置：因为 `F` 严格增且每个水平 `λ ≤ L`，
`∏_i F(β(λ_i−θ)) ≤ F(β(L−θ))·F(β(1−θ))^{k−1}`（`j` 个亚单位级时右端乘 `F(L)^j ≤ F(L)`，
比值 `F(L)/F(1) < 1` 使乘积随 `j` 递减）。
⇒ **门槛只通过一个数 `L` 依赖级内聚合**。

**命题 2（单点边界）** 在该最坏配置上，两侧同时取界给出 `F(β(1−θ)) = φ`、
`F(β(L−θ)) = ψ`，两式相减：

```
β*_pred(T,k,m,s)  =  ( q_φ − q_ψ ) / ( 1 − L(T,m,s) )
```

**命题 3（三种 t-norm 的免疫性）** 对 `product / Gödel min / Łukasiewicz` 三者，
"恰一个通道失效"的级水平都等于 `s`：`product: s·1^{m−1}=s`；`min: s`；
`Łuk: max(0, s+(m−1)·1−(m−1)) = s`。其余水平都 `≤ s`（`product: s^j ≤ s`；
`Łuk: 1−j(1−s) ≤ s`）。故 `L ≡ s` 对**三个 t-norm、任意 m** 成立 ⇒

```
β*(T,k,m,s) 与 T 的种类无关、与 m 无关，恒等于 Phase VII 的律 (q_φ − q_ψ)/(1−s)
```

这就是 P7-O1 的答案（预测形式）。

**命题 4（对照：平均聚合不是 t-norm，但律照样跟着 `L` 走）** 取 `T = mean`（`Σx/m`）作为
**故意越界**的对照：`L = (s + m − 1)/m = 1 − (1−s)/m`，`1 − L = (1−s)/m` ⇒

```
β*_pred(mean,k,m,s) = m · (q_φ − q_ψ)/(1 − s)   —— 比 t-norm 情形大 m 倍
```

若 A5 成立，则"免疫性"不是枚举伪象，而是**定律只对 `L` 敏感**的直接证据（`mean` 的 `L` 变了，常数就变）。

### 1.3 P7-O2：把共享 θ 换成每级自由 θ（`k = 2`）

记 `u_i = F(β(1−θ_i))`、`v_i = F(β(s_i−θ_i))`、`r_i = v_i/u_i`、`P = u_1u_2`。
发放条件 `P ≥ 1−α`；第 `i` 级的静默配置概率 `= v_i·u_{3−i} = r_i·P ≤ α`。于是

```
可行  ⟺  ∃(θ_1,θ_2):  P ≥ 1−α  且  max_i r_i ≤ α/P                      (★)
```

**命题 5（对称系统的自由 θ 不改变门槛）** 给定 `ρ`，`max u_i` 受约束 `r_i ≤ ρ` 的解
`U_i(ρ) = max{F(β(1−θ)) : F(β(s_i−θ))/F(β(1−θ)) ≤ ρ}` 是逐级独立的标量问题；
`P ≤ ∏_i U_i(ρ)`，等号在"每级各取自己的最优 θ"时取得。`s_1 = s_2` 时两个标量问题**同解**
⇒ 最优必为对称点 ⇒ 自由 θ 的可行集与共享 θ **同形**，门槛不变。
（`s_1 ≠ s_2` 时 `U_1 ≠ U_2`，自由 θ 严格占优 ⇒ 这是一个**方向可杀**的预测。）

**命题 6（存在性条件的答复）** 由 (★)：令 `P(ρ) = ∏_i U_i(ρ)`。`P` 随 `ρ` 增、`α/P` 随 `P` 减，
故 `P = Q(α/P)` 有唯一不动点 `P*`，且

```
存在窗口  ⟺  P*(β) ≥ 1 − α                                   （k=2；θ_1,θ_2 自由）
```

最优点上两条静默约束同时取界 ⇒ `r_1 = r_2 = α/P`（"比值均衡"条件）。
**这就是 P7-O2 的答案（预测形式）：存在性条件从"分位差 ≥ 门槛"变成"逐级比值可达标"的
一条不动点等式；在 `k` 级同构时它退化为 Phase VII 的分位差律。**

## 4 分辨率与预算（由推导先固定，不看结果调整）

  点数 `= ceil(span/dθ) + 1`，上限 `MAX_GRID = 200001`；超限者记 `NOT_MEASURABLE` 并在判定中
  **排除出分母**（排除项与数量如实写入 JSON）。
