## 0 本轮要买到的东西

Phase V 的 V1 把 ~0.02 残差**解释**了，但注册归因规则判 **J_NOT_DECISIVE**，原因是 A1（DP 忠实性）
被写成"全部五臂合取"，而两臂（`greedy_first`、`sarsa`）的行为策略**随时间退火**，
其渐近 DP 本就不该忠实。P5-O2 说的正是这件事：忠实性必须**按臂先声明**，而不是事后合取。

⇒ 本轮把每一条臂的行为策略改成**时间齐次**（常数 ε），使每条臂都有一个先验声明的精确对偶，
并把 Phase V 的后验分解（P5-A3）升级为**注册判据 A3**。

## 1 臂集合与先声明的 DP 对偶（六臂 + 一条锚定臂）

| 臂 | 行为策略（时间齐次） | 先声明 DP 忠实 | 步数 |
| --- | --- | --- | --- |
| `annealed_base` | ε 0.3→0.02（**唯一用途：锚定 Phase V 已提交读数**） | **否**（预期不忠实，不参与 A1） | 100 000 |
| `base_c` | ε ≡ 0.02 | **是** | 100 000 |
| `base_long_c` | ε ≡ 0.02 | **是** | 400 000 |
| `noexplore_c` | ε ≡ 0 | **是** | 100 000 |
| `greedy_first_c` | 第一步 ε-贪心（ε ≡ 0.02），自举 `max` | **是**（不动点选择：DP 与采样器同从 Q≡0 起、同样并列取首元素） | 100 000 |
| `sarsa_c` | ε ≡ 0.02，自举为行为策略期望 | **是** | 100 000 |
| `eps30_c` | ε ≡ 0.30（高探索对照） | **是** | 100 000 |

q 网格 `{0.5, 0.6, 0.7, 0.8, 0.9, 1.0}`，种子 `range(10)`，读out 与 Phase III/IV/V 完全相同。

## 2 判据（先固定，按序读）

| 编号 | 判据 | 容差 |
| --- | --- | --- |
| **A0（锚定）** | `annealed_base` 的 10 种子均值 ↔ `phase5_results.json` 的 `V1.rows["base|q"].mc_mean` | **≤ 0.005**；任一 q 超界 ⇒ 本轮 NOT_VALID |
| **A1（按臂 DP 忠实）** | 每条**声明为忠实**的臂、每个 q：`|MC − DP(该臂)|` | **≤ 0.008** |
| **A2（偏差住在不动点）** | 中段 q∈{0.6…0.9}：`max|DP − 律(1/2)| / max|MC − 律(1/2)|` | **≥ 0.75** |
| **A3（闭式解释律）** | 对每个 q：`|MC(base_c) − 闭式(q)|`（A3 只作用于 `base_c`——它就是 Phase III/IV/V 所要解释的那条管线；其余臂是消融，不参与 A3） | **≤ 0.008** |

闭式（**本轮注册为待检验主张**，不再是后验）：

```
P(B可用 | max=0.9) 的先验 = 2/5      （由 mask 抽样 3/8, 3/8, 1/4 直接得出）
p_c = 先验·q / (先验·q + (1−先验)·(1−q))        c ∈ {0,1}
w(p) = (p/3) / (p/3 + (1−p)/2)                 （第一步均匀覆盖 ⇒ 访问加权）
Δ_closed(q) = γ (v_B − c) · (w(p_1) − w(p_0))
```

## 3 判定规则（互斥，按序取第一条成立的）

| 出口 | 条件 | 结论措辞 |
| --- | --- | --- |
| **J_LAW_PRIOR** | A0 ∧ A1 ∧ A3 全过 | L3 的 ~0.02 **不是学习器偏差**：住在解析律的条件先验（1/2 应为 2/5）与探针的访问加权里；学习器精确收敛到自身算子的不动点 |
| **J_FIXED_POINT** | A0 ∧ A1 过、A3 不过、A2 过 | 残差是指定估计器算子的不动点性质（与 Phase III/IV 的"律"无关），但闭式未穷尽它 |
| **J_TRANSIENT** | A0 ∧ A1 过，且 `base_long_c` 把中段偏差降到 `base_c` 的一半以下 | 残差是有限样本瞬变 |
| **J_NOT_DECISIVE** | 以上皆不成立 | 保持未决定性，不得写机制解释 |

**A1 失败的处理（写死，防 cherry-pick）**：若个别臂 A1 不过，须逐臂列出并说明其**先声明的假设**是否被违反
（例如该臂存在多个不动点）；出口只按上表取，**不得**改为"通过的臂合取"。
