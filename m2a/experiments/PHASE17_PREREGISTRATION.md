## 0 有哪几层离散化（这是本轮的全部根据）

门槛判据是 `∃θ：F(β(1−θ))^k ≥ 1−α 且 F(β(lo−θ))·F(β(1−θ))^{k−1} ≤ α`，把它变成可算的东西需要三层近似：

| 层 | 已注册口径 | Phase XIV/XVI 是否导出过容差 |
| --- | --- | --- |
| **L1 截断**：θ 从 ℝ 限制到区间 | `THETA = [0.5 − h, 0.5 + h]`，已提交 `h = 1.0` ⇒ `[−0.5, 1.5]` | **没有**（X-50 指出的正是这一层漏了） |
| **L2 网格**：区间内取有限节点 | `n = 20001 / 40001` | 有（`s = |δ̂(40001) − δ̂(20001)|`） |
| **L3 二分**：β 的求根 | 绝对 `1e-9`（相对 `7.6e-11`） | 有，且比 L2 小四个量级 |

XVI 的失败说明"只用 L2 的位移当误差标尺"不成立。本轮因此**同时**扫 L1 与 L2。

## 1 配置与主读数（先固定，不看结果）

配置集 `H × N = {0.5, 1.0, 2.0} × {20001, 40001}`，节点降序排列与 `p11/p14` 逐字相同；
`k ∈ {2, 3, 4}`，`J ∈ {10,20,40,100,200,400,800}`，`kind ∈ {logistic, probit, gumbel}`，`lo_J = 0.5 − 0.5/(J+1)`。

```
主读数  δ̂_prim(J; k) := δ̂ 在 (h = 2.0, n = 40001) 处的值        —— 两层都"更不近似"的那一个
密度层  L2(J; k)      := |δ̂(h=1.0, n=40001) − δ̂(h=1.0, n=20001)|
截断层  L1(J; k)      := |δ̂(h=2.0, n=40001) − δ̂(h=1.0, n=40001)|
每格两层合计  L(J; k) := L1 + L2
本轮容差      T₁₇     := 3 · max over all (kind, k, J) of L(J; k)      —— 由仪器自报，不由我挑
```

另报一条**收窄方向**的探针（不进入判据，只用于诊断截断是否单边生效）：
`L1⁻(J; k) := |δ̂(h=1.0, n=20001) − δ̂(h=0.5, n=20001)|`。若 `L1 ≡ 0` 而 `L1⁻ > 0`，说明截断只在区间小于某个阈值时才咬；若两者都 `≡ 0`，则 **XVI 的 k 依赖残差不来自截断层**，须改口为别的层（这是本轮要回答的核心问题之一，无论答案是哪个都如实登记）。
