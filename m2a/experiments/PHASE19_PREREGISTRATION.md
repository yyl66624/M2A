## 0 本轮要回答的问题（先写死）

文献侧给到两条形式约束：

- **R14（Burke 2026，正文原句）**：`removal of up to 19 out of 20 cue–reward experiences has zero impact…
  if total conditioning time is maintained` ⇒ 在**总时长固定**下，配**对次数**近乎无关；起作用的是**间隔**。
- **R15（冻结资产，形式结果）**：**时间重标不变性**（time-rescaling invariance）。

于是「任何记忆机制必须满足」的必要条件被写成两个可执行操作：

- **操作 A（抽稀 / thinning）**：固定总时长 `T`，把配对次数从 `n = 20` 削到 `n = 1`（间隔按 `T/n` 拉开）。
  机制的终态应当**近似不变**（对 `n` 不敏感）。
- **操作 B（重标 / rescaling）**：固定 `n`，把整条时间轴乘以 `c ∈ {0.5, 2}`。
  机制的终态应当按 `c` **协变**（即：把纯时间型机制的自变量同时缩放后，读数落在同一曲线上）。

**检验本身**＝这两个条件同时施加。本轮的科学主张不是「某机制是对的」，而是：
**这条检验能否把纯机制类筛开**（有区分力），以及**混合型是否两者都过**。

## 1 被测机制（三类，全部本轮新写，确定性，无随机流）

| 代号 | 机制 | 递推 | 先验预期（写在跑之前） |
| --- | --- | --- | --- |
| **M1 次数记忆** | 每次配对加固定增量，无时间项 | `V ← V + η` 于每个事件时刻，`t` 不进入 | A **必失败**（终态 ∝ n），B 失败（与时间轴无关 ⇒ 谈不上协变） |
| **M2 纯时间记忆** | 连续指数痕迹，不由事件驱动 | `V(t) = V₀·e^{−t/τ}`，事件不写入 | A **必过**（终态只依赖 `T`）；B 只在 `τ` 同时缩放时过，`τ` 固定时**必失败** |
| **M3 事件驱动 + 时间衰减（混合）** | 标准 TD 痕迹 | `V ← λV + η` 于事件时刻，`λ = e^{−Δt/τ}` | A、B 都**应当**过：A 因为间隔进入 `λ` 从而抵消次数变化，B 因为 `Δt` 与 `τ` 同步缩放 |

`η = 0.1`，`τ = 1.0`，`T = 10.0`，`n ∈ {1,2,5,10,20}`，`c ∈ {0.5, 1, 2}`，`λ = exp(−Δt/τ)`。
本轮**不使用随机数**；种子池与既往轮次**天然不相交**（R4 以「不使用」满足，登记于此以免歧义）。

## 2 判据（数值与口径先固定）

先做**分辨率推导**（R5），不许事后按结果调：

- 事件时刻用精确有理格点 `t_i = i·T/n`，`Δt = T/n` 精确 ⇒ **A 侧无离散化误差**，唯一误差源是浮点。
- B 侧缩放作用于 `Δt` 与 `τ` 两者，仍为解析式 ⇒ 同样只有浮点误差。
- 因此容差由**浮点与指数求值**给出，取 `tol := 1e-12`（绝对），并对每个读数报告**能区分的最小差**（R7）：
  即 `tol / 实际差`，且当实际差恰为 0 时按 R14 记「比值无定义」而**不得**读成「无误差」。

| 判据 | 文本 | 口径 |
| --- | --- | --- |
| **C19-1 仪器锚定** | 三类机制在无缩放、`n=20` 下的终态，与本轮**独立实现的闭式**（M2 闭式 `V₀e^{−T/τ}`、M1 闭式 `nη`、M3 闭式 `η(1−λ^n)/(1−λ)`）比对，绝对差 ≤ `1e-12` | 逐条报 `tol/observed` |
| **C19-2 检验有区分力** | 三条同时成立：(a) 存在机制类**过 A 而 fail B**；(b) 存在机制类**fail A**；(c) 三类在 `(A,B)` 上的通过模式**不全相同**（至少两种不同模式） | 布尔；「过」＝终态相对变化 ≤ `1e-12`。（原写法要求「另一类过 B 且 fail A」，见 §5 P19-A1） |
| **C19-3 混合类双过** | M3 在 A（`n=1..20` 全部）与 B（`c=0.5,2`）下均 ≤ `1e-12` | 全部格点 |
| **C19-4 方向性** | M1 的 A 侧终态对 `n` **严格单调递增**；M2 的 B 侧读数对 `c` **严格偏离**协变预测（不是数值噪声） | 严格不等式，报最小步长 |
