## 0 被测族（解析式在跑之前写死）

固定 `η = 0.1`、`τ = 1.0`、`T = 10.0`、`V₀ = 1.0`、`n ∈ {1,2,5,10,20}`、`c ∈ {0.5,1,2}`。
幂指数 `p ∈ {0, 0.5, 1.0, 1.5, 2.0}`。两类遗忘结构：

| 族 | 写入规则 | 终态闭式 |
| --- | --- | --- |
| **N(p)** 无遗忘 | 每次配对写入 `ηΔt^p` | `V = η·n·(cT/n)^p = η·c^p·T^p·n^{1−p}` |
| **F(p)** 连续遗忘 | 写入 `ηΔt^p`，每间隔乘 `λ = e^{−Δt/τ_eff}` | `V = ηΔt^p·(1−λⁿ)/(1−λ)`（`λ<1`；`λ→1` 退化为 `ηΔt^p·n`） |

参考类：**M2**（纯时长积分器，XXI 中唯一三条全过者）一并入表作为基准。
S 约定下 `τ_eff = τ`；V 约定下 `τ_eff = cτ`（与 XX/XXI 完全相同）。

**代数先验（写在跑之前，逐条可判）**：

1. N(p) 过 A ⟺ `p = 1`（因 `V ∝ n^{1−p}`）⇒ 预期 A-passing(N) = {N(1)}；
2. F(p) 无一过 A（有限 `n` 的离散化偏差为 `O(Δt^{min(p,1)})`，远大于 `1e-12`）；
3. 任何 `p > 0` 的族在 V 约定下仍带因子 `c^p` ⇒ **全部不过 V**；`p = 0` 时 `c^0 = 1` 过 V 但（N(0)=M1）不过 A、不过 S；
4. 故预期**同时过 A 与 V 的只有 M2** ⇒ 「三条全过」的唯一性在整族上成立，而非只在五个点上成立。
