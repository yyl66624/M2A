## 2 L3 的律，按确证结果改写

被 Phase III/IV 当作"表征质量律"使用的 `Δ(q) = γ(v_B − c)(2q − 1) = 0.36(2q − 1)` **在中段系统性偏高**，
其误差有两个来源，二者都已在本轮分别定量：

```
先验：P(B可用 | max=0.9) = (1/4)/(1/4 + 3/8) = 2/5          （不是 1/2）
后验：p_c = (2/5)q_c / ((2/5)q_c + (3/5)(1−q_c))
覆盖：w(p) = (p/3)/(p/3 + (1−p)/2)      ← 第一步外生均匀，|avail| = 3 或 2
Δ_closed(q) = 0.36 · ( w(p_1) − w(p_0) )                   （q_1 = q, q_0 = 1−q）
```

在 q=0.8：`0.2160 → 0.2104`（先验项）`→ 0.1944`（覆盖项），实测 `0.1954 ± 0.0007`。

**学习器侧无偏**：D4 表明同一不动点在不同种子上重现（≤0.0011），D3 表明它与精确枚举的条件期望一致。
⇒ Phase IV §3 写的"残余偏差归因于学习器，而非律"**方向错误**，本轮予以更正（原文件按纪律不改，更正登记在此与负面日志）。
