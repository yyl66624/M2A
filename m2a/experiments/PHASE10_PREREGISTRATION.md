## 1 推导（运行前写死；判据全部由本节生成）

### 1.1 平滑族的一般形式

分位展开 `q_p(Λ) = Λ + z√Λ + e₀ + e₁/√Λ + O(Λ^{-1})` 中，`e₀` 是一阶（偏度）项、`e₁` 是二阶项，
二者都是**计数单位上的加性常数**。Phase VIII 用 `e₀ = 2c₁`，`c₁ = (z²−1)/3`，`z = z_{0.95} = 1.6448536`。
把两侧门槛的可行性条件 `b − a ≥ z(√a + √b) + (两侧加性项)` 写成关于 `R = √ρ*` 的方程（`a = ρs`、`b = ρ`、
`Δ = 1 − s`、`B(s) = z(1 + √s)`）：

```
ΔR² − B(s)R − e₀ − e₁/R = 0                                  (★)
```

`e₁ = 0` 时 (★) 就是 Phase VIII 的一元二次方程（正根 `R = [B + √(B² + 4e₀Δ)]/(2Δ)`）。
(★) 对 `R` 单调（左端在 `R > 0` 递增、`R → 0⁺` 时 `→ −∞`），故正根**唯一** ⇒ 求根可用二分，无需 `numpy.roots`。

### 1.2 局部斜率的闭式（本节是本轮的主张）

对 (★) 沿 `s = 1 − Δ` 取全导数，`B_s := dB/ds = z/(2√s)`：

```
slope(s) := d ln ρ* / d ln Δ = − 2Δ(R + B_s) / ( B + 2e₀/R + 3e₁/R² )          (◆)
```

`e₁ = 0` 时利用 `BR = ΔR² − e₀` 可化为等价形式

```
slope = − 2 ( 1 + B_s/R ) / ( 1 + e₀/(ΔR²) )   =   − 2 ( 1 + z/(2√(sρ)) ) / ( 1 + 2c₁/((1−s)ρ) )
```

**结构性读法**：分子项 `z/(2√(sρ))`（来自 `B(s)` 本身随 `s` 变化）把 `|slope|` **推高**过 2；
分母项 `2c₁/((1−s)ρ)`（加性偏度项）把 `|slope|` **压低**到 2 以下。二者量级都是 `O(ρ^{-1/2})` 与
`O(ρ^{-1})`，且 `s` 依赖不同 ⇒ **不存在使 (◆) 在整个区间恒等于 −2 的常数 `e₀, e₁`**：
`slope = −2` 等价于 `B_s/R = (e₀ + 3e₁/(2R²)·(B/(ΔR) 的剩余项))/…`，逐点求解得到的 `e₀` 依赖 `s`。
手算检查（`s = 0.8`，`e₀ = 2c₁ = 1.137`）给 `R = 15.93`、`slope = −2.0685`，
与 Phase VIII 大端拟合 **−2.0620** 同号同量级 ⇒ 公式至少不是空的。

### 1.3 弦斜率与局部斜率的区别（P8-O2 的候选诊断量）

区间拟合得到的是**弦斜率** `chord([a,b]) = Δlnρ/ΔlnΔ`，等于 (◆) 在区间内某点的值（中值定理），
因此**单区间弦斜率不能识别齐次性**：给定任意有限个自由加性系数，都可以把某个区间的弦斜率调成 −2.000，
而局部斜率在该区间内仍然偏离 −2。可操作的诊断量取两件东西：
① 局部斜率闭式 (◆)（它显含工作点 `ρ`，不需要拟合）；
② **两嵌套区间弦差** `|chord([s₀,s₁]) − chord([s₁,s₂])|`，齐次律要求它为 0。
