## 2 `P13-O2` 的答案：不是"网格不够细"，而是"信息只够一侧"

Phase XIII 的 D1 把"二参数拟合没赢过单参数拟合"判负，输在 `3e-6`。本轮把它换成有下限的表述：

```
Δ / T = 0.0397      ⇒  D1 判负的那次比较，差距只有仪器自身一步变化的 4%
e₁ ∈ [0, 0.011404]  ⇒  数据能排除 e₁ ≳ 0.011，但给不出双侧估计（最优点在域边界 e₁ = 0）
指数在集合两端差 6.3e-5  ⇒  "计数系统不是 −2 幂律"这个科学主张对 e₁ 取集合内任何值都不动
```

三条合起来就是 `P13-O2` 的答复：**联合拟合对 `e₁` 的信息量是"上界"量级的，且这个信息量对项目的
科学结论没有影响**。`P12-O1`（Phase XIII 的 P13-O2 前身）要求的"可辨识性设计"到此为止——
再加细网格不会把 `e₁` 变成可估计量，因为**目标是边界解**。

## 3 P15-A4：一次**去掉假阳性**的运行前更正（必须写清方向）

作废版 C2 写的是"被识别集宽度 ≤ 一个搜索步 `0.01` ⇒ 不可估计"，且 P15-A1 把二分限制在 `[0, 0.01]` 内。
两条都有问题：

- **R8 违例**：当被识别集覆盖整个允许域时，二分器只能返回域端点。门控 G7 在跑前就打印出这个退化
  （`profile(0.01) − joint = 7.086e-5 < T`，即步长处**没有**违反点），而作废版的代码会把
  `0.0099994 ≤ 0.01` 当成 C2 通过——**判据被仪器自己的定义满足**。
- **方向反了**：比一步还窄的集合是**更紧**的界定，不是"不可估计"；真正没有信息的是集合顶到盒边界。

**关键披露**：按修正后的真实括号，`e₁_max = 0.011404 > 0.01`，所以**作废版的字面主张其实为假**；
若不撤掉它，它反而会因端点假象**误判为真**。因此 P15-A4 的效果是**去掉一个假阳性**，
而不是把失败改成成功——这一点与 Phase XIII 的 P13-A5、Phase XIV 的 P14-A5 同属"方向写反"类，
但那两次是避免假阴性，这一次是避免假阳性，登记时须分清。
