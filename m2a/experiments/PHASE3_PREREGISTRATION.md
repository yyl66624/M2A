## 1 L1：合取 = **驱动轴的重标定**（不是另一种函数形式）

**解析命题**：对乘性合取 `p_and = σ(β(x₁x₂ − θ))` 与析取 `p_or = σ(β(x₁+x₂ − θ))`，

```
p_and(1,0) = σ(−βθ)                          （单路静默侧）
p_and(1,1) = σ(β(1 − θ)) = p_or(1,0)          （恒等式：合取的联合响应 = 析取的单路响应）
单路静默边界：θ_s(β) = |logit α| / β           （α = 0.05）
联合点火边界：θ_j(β) = 1 − |logit α| / β
合取窗口：θ ∈ [θ_s, θ_j]，**存在当且仅当 β ≥ 2|logit α| ≈ 5.89**
窗口宽度：θ_j − θ_s = 1 − 2|logit α|/β
```

### 1.1 运行前修正（P3-A1）

原稿把单路静默写成 `σ(β(1−θ))`，那是**析取**的单路式；**乘性合取**在单路时 `x₁x₂ = 0`，
故为 `σ(−βθ)`。用错式子会把边界写成 `1 + |logit α|/β`（恒大于 1，永远无解），
与 Phase II 观测到的 `and` 单路 0.049（θ=0.5, β=6）直接矛盾。**已在运行前改正**；
改正后多出**一条非平凡结论**：合取窗口的存在本身要求增益 `β ≥ 2|logit α|`。

**检验**：`β ∈ {2,4,6,8,10}`；在 `θ ∈ [0,1.5]` 上以 0.002 步长扫描，
求 `p_and(1,0) ≤ 0.05` 与 `p_and(1,1) ≥ 0.95` 同时成立的 θ 区间，与 `[θ_s, θ_j]` 比较。

| 判据 | 容差 |
| --- | --- |
| `|p_and(1,1) − p_or(1,0)|`（解析） | **< 1e-12**（恒等式） |
| 经验窗口端点 vs `θ_s, θ_j` | **≤ 0.01**（β ≥ 6 的三组） |
| β ∈ {2,4} 时窗口**不存在**（θ_s > θ_j） | 必须复现 |
| 窗口宽度 = `1 − 2|logit α|/β` | 与实测差 **≤ 0.01** |
| 同一 (β,θ) 下 `p_and(1,1)` 的蒙特卡洛估计 vs 解析 | **≤ 0.02** |

**废条件**：任一 β 的边界偏差 > 0.02 ⇒ L1 的"驱动重标定"表述不成立。

## 2 L2：门的符号律 `sign(∂p/∂x) = sign(2o − 1)`

**模型**：带"开放度" `o ∈ [0,1]` 的门：`p(x; o) = σ(β(x·(2o − 1) − θ))`。

**解析命题**：响应方向由开放度的**中立点 0.5** 决定；`o < 0.5` 时增大输入**降低**行动率。

**检验**：`o ∈ {0.0, 0.25, 0.5, 0.75, 1.0}`，β=6，θ=0.5；在 `x ∈ [0,1]` 上算 Spearman ρ 与端点差。

| 判据 | 容差 |
| --- | --- |
| `o ≠ 0.5` 时 `sign(ρ) = sign(2o−1)` | 全部 4 个格 |
| `o = 0.5` 时曲率为平（`max|Δp|`） | **< 0.01** |
| 饱和掩蔽：`o=0.25` 且 `θ=0.2` 时，`x>0.8` 段的斜率 | **< 0.02** |

**废条件**：任一 `o ≠ 0.5` 的符号不符 ⇒ L2 不成立。

## 3 L3：表征质量律 `Δ(q) = γ·(v_alt − c)·(2q − 1)`

**背景**：Phase II 的 E2 中 `S_only` 的 Δ=0 是**构造性**的；`S_proxy` 因状态自环而**撤回**。
Phase III 用**修正设计**把"表征质量"变成连续变量：

```
状态 = (剩余最大值, 步数, 线索 cue)     ← 步数消除自环
线索精度 q = P(cue = 1 | B 可用) ∈ {0.5, 0.6, 0.7, 0.8, 0.9, 1.0}
探针：step=1, max=0.9, cue ∈ {0,1} ⇒ Δ = |Q(A|cue=1) − Q(A|cue=0)|
```

**解析命题（P3-A3 修正后）**：探针状态的最大值为 0.9，而它**只能**来自掩码 `[1,0]` 或 `[1,1]`；
**以该状态为条件**，先验变为 `P(B 可用) = 1/2`，故后验差恰为 `(2q − 1)`：

```
Δ(q) = γ·(v_B − c)·(2q − 1) = 0.36·(2q − 1)
```

⇒ `q = 0.5` 时 Δ=0（无信息线索）；`q = 1` 时 Δ=0.36（完全表征）；`q = 0.8` 时 Δ=0.20。

| 判据 | 容差 |
| --- | --- |
| 每个 q 的 `|Δ_emp − 0.36·(2q−1)|` | **≤ 0.03** |
| `q = 0.5` 的 Δ | **≤ 0.01** |
| 单调性：Δ 随 q 不减 | Spearman ρ = 1 |

**废条件**：任一 q 的偏差 > 0.03 或单调性被破坏 ⇒ L3 的线性形式不成立。

### 3.1 运行前修正（P3-A2 / P3-A3）：三处设计错误

1. **公式错**：原稿写 `Δ(q) = 0.36(2q−1)`，隐含"P(B|cue)=q"，但先验是 2/3，
   正确形式是**后验差**（上式）。这一错误会让 q=0.8 的预测从 0.20 变成 0.216，看似小，
   但 q=0.5 时两者都给出 0，掩盖了"后验"与"准确率"的区别。
2. **采样偏差（P3-A2）**：首动作若用 ε-greedy，A 几乎只在 B 不可用时被选中，Q(A) 的更新目标
   来自**行为策略偏置**的分布，收敛到 0.8 而非后验加权值（门控 C5 以 0.000 的精确零暴露了它）。
   修正：**首动作均匀随机**（保持 Q-learning 的 off-policy 有效性需要覆盖），第二步贪心。
3. **先验条件化错误（P3-A3）**：P3-A2 用**无条件**先验 2/3，但探针状态 `max=0.9` 排除了
   `[0,1]`，条件先验为 **1/2**，故正确形式回到 `0.36(2q−1)`。另外收敛预算从 20,000 步
   提高到 **100,000 步**：20,000 步时三个种子的 Δ 跨度为 0.143–0.267（SD 超容差），
   100,000 步时收敛到 0.211–0.240（均值 0.221，与 0.216 相符）。**步数是收敛预算，不是结果调参**。

两处均在**任何格被读取之前**写入。

**并与 Phase II 对照**：`S_only`（无可用性维度）应保持 Δ=0（负对照）；`S_plus_C`（q=1 的极限）应给出 0.36。
