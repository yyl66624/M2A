# M2A Phase V-b 预注册：串联链门槛律的**重测**（只换仪器，不改科学容差）

> 日期：2026-10-18 ｜ 状态 **v1（先于运行写定）** ｜ 前置：`PHASE5_RESULTS.md` §3（V3-C4 FAIL）
> 本轮**不是**对 V3 的重判。V3 的判定保持 REFUTED(C4)。本轮是一轮新的预注册，唯一变化是**仪器分辨率**，
> 而分辨率要求在本文件里由**推导**先固定，科学容差 `相对 ≤ 2%` **逐字沿用** `PHASE5_PREREGISTRATION.md` §3.2-C4。

---

## 0 为什么要重测（只引用已提交事实）

`critical_beta` 在 θ 网格上判窗口存在性。设网格步长 `dθ`、驱动间隙 `Δ`、预测门槛 `β* = κ_F/Δ`，
则离散化使检测到的门槛偏移量级为

```
δβ*  ~  β* · dθ / Δ  =  κ_F · dθ / Δ²
```

Phase V 用 `dθ ≈ 1.5e-4`（4001 点 / 跨度 0.625…1.5）、二分容差 1e-3。
在 `Δ = 0.0625` 时该下界 `δβ* ≈ 5.89·1.5e-4/0.0039 ≈ 0.22`，**已经大于**注册的绝对容差 0.05。
⇒ 那 2 格的超限与"律是否成立"无关，是量具不到（`PHASE5_RESULTS.md` §3.3 的加密复核为事后证据，不门控）。

## 1 仪器规格（先固定）

| 项 | 要求 | 依据 |
| --- | --- | --- |
| θ 网格步长 | `dθ ≤ 0.0002 · Δ`（由 §0 推导使 `δβ*/β* ≤ 0.02%`，比科学容差 2% 严 100 倍，且满足 VB-2 的 0.005） | §0 推导 |
| 网格点数 | `ceil(跨度 / dθ) + 1`，上限 200 001 点；若触顶则该格记 **NOT_MEASURABLE** 并登记（不得放宽 dθ） | 运行时间有界 |
| 二分容差 | `≤ 0.0002 · β*_pred` | 与 dθ 同阶或更严 |
| 其余一切 | t-norm、基底、`α=0.05`、36 格组合、`κ_F` 公式 | **与 Phase V §3 完全相同，不得增删** |

## 2 判据

| 编号 | 判据 | 容差 |
| --- | --- | --- |
| **VB-1** | 36 格数值 `β*` ↔ 解析 `κ_F/Δ` 的**相对**误差 | **≤ 2%**（逐字沿用 V3-C4） |
| **VB-2** | 还原性负对照（m=1、o=1、硬 AND、logistic）↔ Phase IV 常数 5.889 | ≤ 0.005 |
| **VB-3** | 死门格（含 `o=0.5`）：`β ≤ 200` 内无窗口 | 全部通过 |
| **VB-4** | 与 Phase V 的 `β*` 读数在**同一格**上的差 ≤ `κ_F·dθ_old/Δ²`（即：差异只能由分辨率解释） | 逐格核验 |

**判定**：VB-1 ∧ VB-2 ∧ VB-3 ∧ VB-4 ⇒ 本轮 **SUPPORTED**；任一不过 ⇒ **REFUTED**。
两者都**不修改** V3 的判定；只有本轮 SUPPORTED 时，正文才允许写
"串联链的门槛律在其科学容差（相对 2%）下于加密仪器上成立，而 Phase V 的绝对容差对 `Δ≤0.11` 的格不可达"。
