## 5 创新点（分级，按证据强度）

### I1（最强）：**省略 = S 层 ⊕ C 层的合取**

- **内容**：选择性不响应（S）无需表征；"省略"作为一等机制还要求**反事实可及性表征**（C）——系统把被跳过的选项表示为"可用且可评估"。
- **证据**：21 条全文（物理化学的 S 层实例 6 条；表征系统的 C 层实例）＋ E2（构造性）＋ L3（定量：敏感度随证据量线性上升）。
- **新颖性**：介于**新定义**与**新假说**之间。Day 1 文献里"省略/弃权"没有这个分层；但"表征是反事实推理前提"本身不是新思想。
- **可证伪**：若存在无表征却对"可用性"敏感的系统 ⇒ 假说被否证。

### I2（中 → 中上）：**合取窗口的分位差律 `β ≥ q_{1−α}(F) − q_α(F)`**

- **内容**：合取不是"标签"，而是一个有**增益门槛**的机制：增益不足时，任何阈值都无法同时做到单路静默与双路点火；
  门槛的数值由**噪声分布的分位差**给出。
- **证据**：解析推导 + 蒙特卡洛（5 个 β）+ **三个独立基底**（logistic 5.889 / probit 3.290 / Gumbel 4.067，
  数值复现误差 ≤0.002）。
- **诚实定位**：单基底时是初等代数；**跨基底**后升级为"形式与分布无关、常数可预测"的条件——
  仍不是经验发现，但已不是参数化巧合。

### I3（方法学）：**触发/门的可测签名**

- **内容**：触发 = 单向单调；门 = 符号可翻转（由开放度相对 0.5 决定）；约束 = 饱和。
- **证据**：E1b + L2。
- **用途**：把跨域机制比较从"类比"推进到"同一组可测签名"，直接服务 M2A 的桥接判据（B-01/B-04 目前是 ANALOGY-ONLY）。

### I4（负结果，同等重要）：**K4 的覆盖缺口是结构性的**

- 补入 7 条后覆盖仍 3/8；新增全部落在 G3/G4。⇒ 这不是检索失败，而是文献分布本身。

### 10.1 对 §4.1 与 §2.3 的更正（L3 归因方向反转）

§4.1 末行原写"Phase III 的残余偏差归因于学习器，而非律"。Phase V 的精确算子给出相反方向：

```
0.36(2q−1)  ──先验 1/2 → 2/5──►  状态层律  ──访问加权──►  w(p)=2p/(3−p) 的闭式
q=0.8:  0.2160  ──►  0.2104  ──►  0.1944  = DP(1.4e-13 内) ≈ MC 0.1945
```

⇒ **残差住在解析律的条件先验与探针的访问加权里，学习器精确收敛到自身算子的不动点**。
并且 `p4_mechanisms.bayes_sensitivity` 用 `rng.rand() < 0.5` 抽样 B 可用性，与律**共用先验**，
所以"独立估计器与律逐格精确一致"不构成对先验的独立检验（该支实测 q=0.8 给 0.2140）。
证据分级修正：L3 的"中强（模拟中段有 ~0.02 系统偏差，未解释）"应读作
**"律的条件先验写错，修正后与精确算子在 1e-13 内一致"**。
