# O-06｜[MOTION SOURCE] 槽的判别式设计（仅设计，不实施）

> 来源：`08_OPEN_QUESTIONS.md` O-06、`07_CONTRADICTIONS_AND_COUNTEREVIDENCE.md` C-01（裁定 **未决 / UNCERTAIN**）。
> 状态：**设计交付**。本文件不新增任何实验、不改动 412 行账本、不改动任何既有标注；
> 它只规定「将来填这个槽位时，依据什么填、什么情况下必须不许填」。
> 结论级别：**方法设计**，不是证据；`SIMULATION_RESULT` 一词在此不适用。

## 1 两个候选填充各自主张什么

| 记号 | 填充 | 主张 | 文献锚 |
| --- | --- | --- | --- |
| **H-N** | 神经因果链 | 行动的动因是前驱神经因果链；「我意愿了」只是链条上的一个可报告标记，不是推动者 | G7-06（Libet：RP 先于意愿报道约 350 ms）、G7-05（Wegner：意志感可为事后建构） |
| **H-R** | 理由结构 | 行动的动因是使该行动可理解的理由—原因结构；无理由结构者按 M2A 事件语法根本不构成「行动」 | G7-02（Davidson：理由—原因是行动的构成性条件） |

C-01 的裁定是「未决」，因此本设计的义务**不是**在两者间选一个，而是给出**可判别**的填法规则：
在什么样的记录上，两种填法会给出不同答案；在什么样的记录上，它们原则上不可分、因而必须留空或填混合值。

## 2 判别观测量（记录层可得，不依赖新测量）

- **D1 时序一致性**：记录内「意愿报道时点」与「动作时点」的先后。文献侧可读（Libet 类范式自带时序）。
- **D2 理由可及性**：文本是否给出 `because…` 结构，且该理由与动作内容**一致**（理由替换后动作描述随之改变才算一致）。
- **D3 反事实敏感性**：把理由抽掉或替换后，读者是否仍把它算作**同一个**行动。仍算 ⇒ 理由不构成动因（H-N 方向）。
- **D4 干预痕迹**：是否存在外部干预（暗示、催眠、神经调控、强迫）使因果链**不经过**当事人的意愿报道。
  D4 是 H-N 的正面证据，也是 H-R 的反例来源。

四项都只要求记录中**已有**的信息，因此本设计与「真实数据 / 人体实验」授权无关。

## 3 填法规则（四格决策表）

| 条件 | 允许的填充 | 说明 |
| --- | --- | --- |
| D4 有 **且** D2 无 | **神经因果链** | 唯一允许直接填 H-N 的情形；此时禁止填「意识意愿」 |
| D2 有 **且** D1 顺序为「意愿→动作」 **且** D4 无 | **理由结构** | 允许 H-R，但 `触发是否需意识可及` 仍须标为开放参数（C-01 影响条款） |
| D2 有 **但** D1 逆序（动作先于意愿报道） | **MIXED-UNDECIDED** | 两说不可分：事后建构与链条先动都预测此形状。该行进入 C-01 待决队列，不得折算成任何一方 |
| D2 无 **且** D4 无 | **留空 / NOT-ACTION-TRIGGER** | 无证据即不填；沿用 C-01「[MOTION SOURCE] 不得默认填意识意愿」 |

第三格是本设计的关键：它把 Wegner/Libet 与 Davidson 的分歧**留在记录里**，而不是用默认值抹平。
任何一轮批量标注若发现该格占比异常高，说明 D1/D2 的记录质量不足，应先修描述层，而不是先出结论。

## 4 判别力自检（对齐规则 R7 的精神）

规则若不能翻转任何一条记录，就没有区分力——这与 X-29 / W2 的「1 计数容差」教训同形。故规定：

- 每条被填的记录必须同时记录**最小可翻转证据**：删去或反转哪一项 D 观测会使填充改变。
- 报告 **容差/证据比**：把「支持某一填充的证据强度」记为离散格（0=缺项、1=间接、2=直陈、3=有干预痕迹），
  并声明规则只在 ≥2 时填充。低于 2 一律走第三格或第四格。
- 若四格分布在 20 行样本上退化为单一格（>90%），判该判别式**无区分力**，回到 §2 重定义观测量，
  并登记为负面结果（依 `governance/NEGATIVE_AND_NULL_EVIDENCE_LOG.md` 惯例）。

## 5 一致性检验设计（写好但不执行）

- 取 412 行账本的**只读副本** 20 行（分层抽样：覆盖 K1 各子型与至少 3 个域），两名标注者盲标四格。
- 统计：四格分布、逐格 Cohen's κ、以及**分歧类型**（分歧集中在 D1 还是 D2，决定该修时序口径还是理由口径）。
- 通过线（须先注册再执行）：κ ≥ 0.4 且第三格占比 ≤ 30%。不达线 ⇒ 判该参数化在当前记录层不可用。
