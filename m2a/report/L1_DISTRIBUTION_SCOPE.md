# L1 的分布范围：分位差律由构造给出，三族复现是实现检查

> 日期：2026-10-23 ｜ 触发：审稿人 2 的 R2-M2 ｜ 依据：`experiments/PHASE4_PREREGISTRATION.md` §1（对任意单调 CDF `F` 的推导）
> 本文是口径说明，不是新结果；不改变 Phase III/IV 的任何读数或判定。

## 1 命题与证明

两输入加性驱动 `T = x₁ + x₂`，`p = F(β(T − θ))`，`F` 为任意单调 CDF，`q_α = F⁻¹(α)`。

```
单路静默   p(0,0) = F(−βθ) ≤ α        ⇔  θ ≥ −q_α / β
联合点火   p(1,1) = F(β(1−θ)) ≥ 1−α    ⇔  θ ≤ 1 − q_(1−α) / β
窗口存在   ⇔  −q_α/β ≤ 1 − q_(1−α)/β   ⇔  β ≥ q_(1−α) − q_α
```

证明只用两件事：`F` 单调、`q_α` 是分位点。没有用到 `F` 的任何参数形式。

## 2 因此“形式不变”是构造性的

- **对任意单调 `F` 都成立**，不是三个分布族的经验归纳；三个族的常数不同，是因为 `q_(1−α) − q_α` 不同，而不是因为“机制随分布改变”。
- logistic / probit / Gumbel 的复现是**实现检查**（同一推导在三条代码路径上跑通），不是“分布无关”的证据。
- 计数系统 S2 不在本范围内（它不是加性位置-尺度输入），它的失败是**边界测试**，否证的是“通用形式”这一更广表述，不是本节的范围。

## 3 对报告口径的更正

- §4.1 的“跨基底不变性（形式不变、常数随分布）”应读作“**实现一致性**”；它不构成对分布无关性的经验支持。

## 4 可证伪性

若存在一个单调 `F`（在实现中）给出的临界 `β` 与 `q_(1−α) − q_α` 相差超过 MC 容差 `0.05`，则推导或实现有错。这是可复核的预测，不需要新实验。
