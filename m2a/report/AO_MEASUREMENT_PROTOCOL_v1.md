## 1 为什么要换分析单位

Phase XI–XIII 的测度语义问题（`P11-O1`、`P12-O3`）根子在一处：旧口径把「静默」与「发放」当成
**同一事件的两个互补侧**来定义阈值。若两侧都由同一个 `P` 的互补集给出，则
`P(静默) = 1 − P(发放)` 直接成立，双侧窗口在构造上塌缩为一个窗口——判据无论怎么加密网格都无法
把「抑制」与「未驱动」分开。Phase XIII 的 `sup ∉ R` 退化分支（X-38）与联合拟合的 3e-6 噪声判负
（X-39）是同一件事的两种表征。

## 2 模型定义

**行动机会（Action Opportunity）** `o` 是一个四元组：

```
o = (s, W, A, c)
    s : 主体（单机制实例 / 级联系统 / 团队，随层级取，但一次测度内固定）
    W : 有界时间窗（单位与 dθ 口径沿用注册时固定的 θ 网格，不得在结果出来后改）
    A : 该窗口内**可用**的行动类别集合，|A| ≥ 1，元素互斥
    c : 成本/可得性状态（决定 A 是否为空、以及各类别的可达上界 L）
```

**结果测度** `μ_o` 是定义在**类别并集加一个额外类别** `NONE` 上的概率测度：

```
μ_o : {a_1, …, a_k, NONE} → [0,1]，  Σ_{a∈A} μ_o(a) + μ_o(NONE) = 1
```

`NONE` 不是「其余一切的余集」，而是**同一测度上的一个独立类别**（窗口内确实没有任何类别被越阈）。
这一步是换分析单位的全部要点：**互补性写在测度里（求和为 1），而不是写在事件的定义里。**

两个功能量分别定义在 `μ_o` 的不同泛函上，因此不再互相塌缩：

```
发放侧（issuance）  I(o) = max_{a∈A} μ_o(a)          ← 越阈的是「哪一个行动」
静默侧（silence）   Z(o) = μ_o(NONE)                 ← 越阈的是「什么都没发生」
门控判据            θ_I 作用在 I 上，θ_Z 作用在 Z 上，二者是**不同泛函**上的不同阈值
```

在 `|A| = 1` 的特例下 `I(o) = 1 − Z(o)`——即旧口径是新协议的一个**退化特例**，而不是与之冲突的
另一套理论。这一点必须由预检 P3 以还原锚定的方式实测，而不是在文字里宣称。

**层级系统**：`k` 级串联时，每级各自给出 `μ_{o,j}`；`L`-归约（Phase IX–XI 的结论）在协议里的位置是
`I(o) = max_j L_j` 形式的作用域，`sup ∉ R` 的退化分支改用闭包口径（Phase XIII/XIV 的精确速率式仍适用）。

§4 此前只是六段散文——按 X-68 的口径，「列了预检」不等于「预检可跑」。实现时逐条撞出下面三处，
它们都是**协议本身**的口径问题，不是代码问题，因此必须先记下，正式预注册不得原样抄 §4。

1. **§4-P2 按字面会判倒一切正常测度。** 原文「`NONE` 与任何 `a ∈ A` 不同时为正」若读成概率层面的
   陈述，则 `μ(NONE)=0.2, μ(a)=0.3` 这种完全正常的测度直接违规；同一次试验的不同结果本来就可以同时
   携带正概率。实现改为**事件层**：任一网格节点不得同时属于 `NONE` 与某个类别（违反数须为 0，实测 0）。
   ⇒ 预注册必须把这条写清楚是哪个层面，否则判据不可执行。
2. **§4-P5 把「动窗口 W」当成「动网格」。** 三条旋钮里若保留「区间外扩 `h:1→2`」，实测位移
   **1.015e-01**，而真正的网格位移（节点加密 / 半格错开 / 整格错开）只有 **1.746e-04 / 4.794e-04 /
   1.885e-04**——差五个数量级。原因不是精度：外扩 `h` 会让密度重新归一，**改变了被测量本身**，
   把它计入容差等于给一条 1e-15 级的恒等式配一个 1e-1 的界（这正是 R9 那类「把系数搬进已含它的口径」）。
   ⇒ 本轮实现只用网格三旋钮导出容差 **8.425e-04**，窗口灵敏度单独报告、不进容差。
3. **§4-P6 的「独立仪器」按原文没有判别力。** 把 `Z` 从事件定义改成协议禁止的补集定义
   `1 - Σp_a`，在**任何归一化测度上两者恒等**（差 5.6e-17），所以「两条路径一致」这条检查
   对错误定义同样放行——实测就是：门控在被改造成违规口径后仍 **7/7 全绿**。
   ⇒ 补上 `P6c`：构造一个**含未记账质量**的测度（`μ(a1)=0.5, μ(NONE)=0.4`，和为 0.9），
   此时事件定义给 `0.400`、补集定义给 `0.500`（差 0.100），两条定义才分叉。
   加了这条之后，同一个变异被当场抓到（`P6c` FAIL、退出码 1）。**恒等的一致不是证据**，
   这一条与 X-29「容差恰好等于一个格点」、R7「要报出能区分的最小差」是同一族缺陷。
