# B-02｜制度变迁的可测滞回指标（仅设计，不实施）

> 来源义务：`06_MECHANISM_BRIDGE_REGISTRY.md` §B-02（判定 **ANALOGY-ONLY**），
> 其 Phase II 候选写明为「**寻找制度变迁中的可测滞回指标（路径依赖的定量刻画）**」。
> 状态：**设计交付**。不含新数据、不改动 412 行账本、不改动 B-02 判定字、不做任何真实数据采集
> （真实数据/动物人体/付费算力/LLM 训练四类按章程 §0.2.5 未启动）。
> 级别：**方法设计**。跨域机制主张一律不在本文件范围内。

## 1 指标定义（滞回 = 环路，不是「有历史」）

设控制量 `u`（连续或准连续的驱动变量，如费率、配额、外部压力水平），状态量 `s ∈ {A, B}`
（在任一时点**实际生效的制度安排**，二值或多值；多值时逐对状态分别做）。

取一段记录，把 `u` 的单调上升段记为**上行沿**、单调下降段记为**下沿街**，令

- `θ↑ := inf{ u : 上行沿上 s 由 A 变为 B }`
- `θ↓ := sup{ u : 下沿街上 s 由 B 变为 A }`

**滞回指标** `H := θ↑ − θ↓`，并给出**双侧括号** `[H_lo, H_hi]`（由记录分辨率导出，见 §3）。

第二条指标（可选，量纲无关性更差）：环路面积
`Ar := ∫ |P↑(u) − P↓(u)| du`，其中 `P↑/P↓` 为两沿上的状态占比。

**主张纪律**（写死）：
`H > 0` 且括号下界 `H_lo > 0` ⇒ 可主张「存在滞回」；
`H = 0` 且括号包含 0 ⇒ **不得**主张滞回，只可主张「路径依赖（path-dependent）」；
括号跨越 0 ⇒ **读数不可判**，必须登记为 NOT_RESOLVED，不得四舍五入成任何一方。

## 2 为什么这不是「有历史效应」的同义反复

按 B-02 所属 K7 的双稳态语义，滞回与一般路径依赖的区别**必须**落在可观测量上，否则指标空洞：

| 现象 | 上行沿/下沿街行为 | 本指标 |
| --- | --- | --- |
| 无历史 | 两沿在同一 `u` 处给出同一 `s` | `H = 0`，`Ar = 0` |
| 一般路径依赖（有记忆但无开关） | `s` 随 `u` 单调、两沿重合 | `H = 0`，`Ar` 可 > 0 ⇒ 单用 `H` |
| **真滞回（双稳）** | 同一 `u` 上两沿给出**不同** `s`（两沿不重合） | `H > 0` **且**存在 `u` 使两沿状态不同 |

⇒ 判据核心是**两沿不重合（环路存在）**，`H` 只是其量化。仅有 `Ar > 0` 而无状态不重合，
按本设计**不构成**滞回证据（避免把测量延迟、时滞误判成双稳）。

## 3 分辨率先于主张（R5 / R7 / R12 / R14 的落地）

这一节是本设计的实际约束力所在，全部在取值之前固定：

1. **`u` 的量化步长 `δu`**：由记录本身决定（如年度指标取相邻年份差的最小非零值；文本口径取制度参数表的最小改动单位）。
   ⇒ `H` 的可分辨下界 `δu`，`H_lo = H − δu`、`H_hi = H + δu`。
   **小于 `δu` 的滞回不可主张**，只能登记为 NOT_RESOLVED（R7：报告仪器能区分的最小差）。
2. **括号必须由真实区间给出**，不许把搜索限制在判据自己的区间内——那会让域端点自动满足判据，
   造成假阳性（规则 **R12**，出处 X-47）。
3. **状态时点错位**（上行沿与下沿街的时间跨度不同、制度生效有滞后）会伪造 `H`。
   设计要求先做**时滞对齐**：在两沿上分别按 `u` 而非按时间索引，且把 `u` 变化到 `s` 变化的
   记录内最迟延迟 `L_max` 列入括号：`H_lo = H − δu − L_max 的影响界`。
4. **零值处理在注册时选定**（规则 **R14**）：`H` 读数为 0 时不得自动读成「无滞回」，
   必须先确认 §2 的三态表中它落在哪一行。

## 4 记录层可估性（不依赖新测量）

设计只使用**已存在的制度记录**，因此不需要真实数据采集授权：

- **O1 生效安排**：某时点实际施行的规则文本/参数表（判据：是否可见于官方文本，而非草案或解释）。
- **O2 驱动量**：同一记录序列中的控制变量取值（须可排序，允许序数化）。
- **O3 切换时点**：`s` 改变的记录事件；须能同时给出前值与后值。
- **O4 反例记录**：在 `θ↑` 与 `θ↓` 之间区间内，是否存在 `s` 不变的时段（若存在且足够长，`H` 的括号须放宽）。

**缺 O3 或 O1 的记录不得进入估计**（不得用解释性文本补足），这是防止隐喻级相似冒充测量的关键闸门——
B-02 的社会侧之所以是 ANALOGY-ONLY，正卡在 O1/O3 的因果级证据缺失上。

## 5 与生物侧比较的**唯一**允许口径

B-02 映射 R07（正/负反馈双稳，因果级）↔ G3-01（MAPK ultrasensitivity，因果级）↔ G6-04（制度安排）。
本设计规定：

- **可跨域比较**：环路**是否存在**、以及 `H` 的**符号**。
- **不可跨域比较**：`H` 或阈值参数的**数值大小**。理由写在 §B-01 的限制行里已经给过：
  G4-04 的 drift rate 是神经属性而非文本属性，阈值参数不可跨域迁移。
  ⇒ 任何「制度滞回系数 = 某分子 ultrasensitivity 倍数」的表述都是**越界**，须拒收。
